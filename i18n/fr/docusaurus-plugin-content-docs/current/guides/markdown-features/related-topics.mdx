# Sujets connexes

Le composant **Sujets connexes** propose automatiquement du contenu connexe en fonction des balises taxonomiques communes. Il analyse les balises de la page actuelle, identifie d’autres documents comportant des balises similaires, puis les affiche sous la forme d’une liste de recommandations sélectionnées.

## Ajouter des sujets connexes

1. Sélectionnez **Sujets connexes** dans la liste **Intégrer**.
2. Modifiez le composant.
3. (Facultatif) Définissez le **Nombre maximal de résultats** pour contrôler le nombre de sujets connexes affichés (valeur par défaut : 5).
4. **Enregistrez** vos modifications.

## Options de configuration

**Nombre maximal de résultats** : permet de contrôler le nombre de sujets connexes affichés (1 à 20)

## Fonctionnement

Le composant utilise l’algorithme de similarité de Jaccard pour comparer les balises de taxonomie entre la page actuelle et toutes les autres pages publiées. Les pages présentant le plus de balises communes apparaîtront en tête de liste. Le composant n’apparaît que sur les pages comportant des balises de taxonomie et uniquement lorsque du contenu associé est trouvé.

## Bonnes pratiques

* **Utilisez un balisage cohérent** : plus vous appliquez les balises de taxonomie de manière cohérente dans l’ensemble de votre contenu, plus les suggestions de sujets associés seront pertinentes.
* **Emplacement optimal** : placez le composant « Sujets connexes » à la fin de votre contenu pour inciter à la lecture complémentaire.
* **Limites raisonnables** : utilisez entre 3 et 7 sujets connexes pour une expérience utilisateur optimale. Un trop grand nombre de suggestions peut être déroutant.
