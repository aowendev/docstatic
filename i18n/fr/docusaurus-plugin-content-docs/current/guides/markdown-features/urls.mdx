# URLs

Le composant **URL** vous permet de faire référence à un lien externe par le biais d'une clé plutôt que de le coder en dur. Chaque clé est associée à une URL par langue, de sorte qu'un visiteur arrive toujours sur la version adaptée à sa langue de la destination, et qu'un lien qui change ou qui casse ne nécessite qu'une seule correction, quel que soit le nombre de documents qui y font référence.

## Gestion des URL

Vous pouvez modifier la collection « URL » dans le CMS.

1. Cliquez sur l'icône **Ajouter** ( **+** ) pour ajouter une nouvelle **clé**.
2. Sous **URL (par langue)**, cliquez sur l'icône **Ajouter** pour ajouter une **Traduction** pour chaque langue que le lien doit prendre en charge. Attribuez-lui un **code de langue** et l'**URL** de destination.
3. Sous **Texte de lien par défaut (par langue)**, ajoutez une **Traduction** pour chaque langue, en indiquant le texte qu'une utilisation de `<Url>` doit afficher lorsqu'elle n'en fournit pas elle-même.

## Utilisation des URL

1. Sélectionnez **URL Link** dans la liste **Intégrer**.
2. Saisissez la **clé de l'URL** correspondant à une entrée de la collection URL.
3. Vous pouvez éventuellement ajouter des traductions du **texte de lien** pour remplacer le texte par défaut de la clé pour cette utilisation spécifique — la même clé peut être utilisée à différents endroits avec un texte différent.

<Admonition type="caution" title="Le texte du lien n'est pas traduit automatiquement">
  Contrairement à la prose ordinaire, le texte de lien d’une balise `<Url>` n’est jamais soumis à une traduction automatique : l’élément est conservé tel quel lors de la traduction du document, quelle que soit la langue. Si vous ajoutez un texte de lien, renseignez-le simultanément dans toutes les langues prises en charge, dans le document où vous insérez le lien pour la première fois. Une langue omise à ce stade restera manquante jusqu’à ce que quelqu’un modifie la source et l’ajoute manuellement.

  Si vous n’avez pas besoin d’une formulation personnalisée pour une utilisation particulière, laissez le texte de lien vide et le texte de lien par défaut de la clé sera utilisé à la place — ce texte est traduit de manière normale, une seule fois, dans la collection d’URL.
</Admonition>

#### Exemple

<Url urlKey="docusaurus-website" />

## Vérification de l'intégrité des liens

La collection URL héberge également le tableau de bord **Intégrité des liens**, qui indique à la fois les URL stockées ici et tout lien externe encore codé en dur directement dans vos documents — y compris ceux qui ne figurent pas encore dans la collection URL, afin que vous puissiez les trouver et les centraliser. Consultez [Dashboards](/docs/guides/dashboards) pour plus de détails.
