# Chiffres

Le composant « Figures » vous permet d’ajouter des images accompagnées de légendes à une rubrique. Lorsqu’un utilisateur clique sur une figure, celle-ci s’affiche en agrandissement maximal dans une fenêtre contextuelle.

1. Sélectionnez « Figure » dans la liste « Intégrer ».
2. Modifiez le composant.
3. Sélectionnez une image dans le Gestionnaire de médias.
4. Saisissez une légende. Celle-ci servira également de texte alternatif pour les lecteurs d'écran.
5. (Facultatif) Indiquez une taille.
