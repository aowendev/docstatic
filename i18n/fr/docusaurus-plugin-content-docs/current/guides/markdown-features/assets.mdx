# Actifs

Il arrive parfois que l’on souhaite créer des liens vers des ressources (par exemple, des fichiers docx, des images, etc.) directement depuis les rubriques. docStatic gère cela via le dossier « static/ ».

Tout contenu placé dans ce dossier sera accessible depuis la racine du site publié. Par exemple :

```
# Your doc
/website/docs/myFeature.mdx

# Some assets you want to use
/website/assets/docstatic-asset-example.docx
/website/img/docstastic-asset-example-banner.png
```

## Images

docStatic propose deux façons d’ajouter des images aux rubriques. Pour les images intégrées, vous pouvez cliquer sur l’icône **Image** afin d’insérer une image dans une rubrique. Cette méthode est particulièrement adaptée aux icônes (![](/img/docs/example.svg)) et aux petites images. Les icônes doivent être enregistrées sous forme de fichiers SVG pré-redimensionnés. En mode sombre, celles-ci seront inversées et leur espace colorimétrique sera pivoté de 180°.

<Admonition type="tip" title="Conseil">
  Vous pouvez utiliser [Librsvg](https://wiki.gnome.org/Projects/LibRsvg) pour redimensionner des fichiers SVG. Par exemple, la commande `rsvg-convert example.svg -h 12 -f svg -o example.svg` définit une hauteur de 12 points.
</Admonition>

Pour les images plus grandes, utilisez plutôt le composant [Figure](figures.mdx). Il ajoute une légende — également utilisée comme texte alternatif pour les lecteurs d'écran —, redimensionne l'image pour l'adapter à la page et l'ouvre en taille réelle dans une fenêtre contextuelle lorsque l'on clique dessus.

## Fichiers

De la même manière, vous pouvez créer un lien vers des ressources existantes en utilisant le chemin d'accès au dossier static/ dans l'URL. Par exemple :

```
./assets/docstatic-asset-example.docx
```
