# Schémas

Les diagrammes peuvent être générés à l'aide de <Url urlKey="mermaid" /> dans un bloc de code.

## Utilisation

Le CMS prend directement en charge l'édition des diagrammes Mermaid.

1. Cliquez sur l'icône **Mermaid**.
2. Saisissez le code Markdown dans le champ prévu à cet effet.

Cliquez sur **Aperçu** pour visualiser votre diagramme.

<Admonition type="note" title="Remarque">
  À l'heure actuelle, les diagrammes zenUML ne sont pas pris en charge et les diagrammes de type « mind map » peuvent présenter un comportement inhabituel. Il n'est pas possible de prévisualiser tous les types de diagrammes dans le CMS.
</Admonition>

Pour plus d’informations, consultez la section [Mermaid](https://tina.io/docs/reference/rich-text-usage/mermaid) dans la documentation de TinaCMS.

Pour plus d’informations sur la personnalisation de Mermaid, consultez la section <Url urlKey="docusaurus-diagrams" /> de la documentation Docusaurus.

## Exemples

### Diagramme d’architecture

```mermaid
architecture-beta
    group site(cloud)[Site]
    service cms(server)[CMS] in site
    service store(database)[Content] in site
    service pdf(server)[Exporter] in site
    cms:R --> L:store
    store:R --> L:pdf
```

### Diagramme fonctionnel

```mermaid
block-beta
    columns 3
    Parser["Parser"] Resolver["Resolver"] Composer["Composer"]
    space:3
    PDF["PDF"]:3
```

### Diagramme de contexte C4

```mermaid
C4Context
    title Publishing system
    Person(author, "Author", "Writes topics")
    System(cms, "CMS", "Edits content")
    System(exporter, "PDF exporter", "Produces books")
    Rel(author, cms, "Edits")
    Rel(cms, exporter, "Feeds")
```

### Diagramme de classes

```mermaid
classDiagram
    class Chapter {
        +string Title
        +int Depth
        +VisibleBlocks()
    }
    class Book {
        +Compose()
    }
    Book "1" *-- "many" Chapter : contains
```

### Diagramme entité-relation

```mermaid
erDiagram
    TOPIC ||--o{ TAG : carries
    TOPIC ||--o{ SNIPPET : includes
    TOPIC {
        string title
        bool published
    }
```

### Organigramme

```mermaid
flowchart TD
    Start([Start]) --> Input[/Read topic/]
    Input --> Check{Valid?}
    Check -->|Yes| Render[Render PDF]
    Check -->|No| Warn[Warn and continue]
    Render --> Done([Done])
    Warn --> Done
```

### Diagramme de Gantt

```mermaid
gantt
    title Release schedule
    dateFormat YYYY-MM-DD
    section Content
    Draft topics      :a1, 2026-01-06, 10d
    Review            :after a1, 5d
    section Build
    Export PDFs       :2026-01-26, 3d
```

### Graphique Git

```mermaid
gitGraph
    commit id: "init"
    branch feature
    commit id: "diagrams"
    checkout main
    commit id: "docs"
    merge feature
```

### Tableau Kanban

```mermaid
kanban
    Todo
        [Mermaid gallery]
    In progress
        [Syntax highlighting]
    Done
        [Cross-references]
```

### Carte mentale

```mermaid
mindmap
  root((docStatic))
    Content
      Topics
      Snippets
    Output
      Website
      PDF
```

### Diagramme de paquets

```mermaid
packet-beta
    0-15: "Source port"
    16-31: "Destination port"
    32-63: "Sequence number"
```

### Diagramme circulaire

```mermaid
pie title Topics by status
    "Published" : 52
    "In review" : 12
    "Draft" : 6
```

### Diagramme en quadrants

```mermaid
quadrantChart
    title Effort against value
    x-axis Low effort --> High effort
    y-axis Low value --> High value
    quadrant-1 Do now
    quadrant-2 Plan
    quadrant-3 Drop
    quadrant-4 Quick wins
    Search: [0.4, 0.8]
    Theming: [0.7, 0.3]
    PDF export: [0.8, 0.9]
```

### Diagramme radar

```mermaid
radar-beta
    title Output quality
    axis fidelity["Fidelity"], speed["Speed"], size["Size"]
    curve pdf["PDF"]{85, 70, 60}
    max 100
```

### Diagramme des exigences

```mermaid
requirementDiagram
    requirement print_fidelity {
        id: 1
        text: Diagrams must render as vectors.
        risk: medium
        verifymethod: test
    }
    element exporter {
        type: application
    }
    exporter - satisfies -> print_fidelity
```

### Diagramme de Sankey

```mermaid
sankey-beta
Website,PDF,20
Website,Help,15
PDF,Print,10
PDF,Screen,10
```

### Diagramme de séquence

```mermaid
sequenceDiagram
    participant Author
    participant CMS
    participant Exporter
    Author->>CMS: Save topic
    CMS-->>Author: Confirm
    Author->>Exporter: Export PDF
    Exporter->>CMS: Read content
    CMS-->>Exporter: MDX
    Exporter-->>Author: docs-en.pdf
```

### Diagramme d'états

```mermaid
stateDiagram-v2
    [*] --> Draft
    Draft --> Review : submit
    Review --> Draft : changes requested
    Review --> Approved : approve
    Approved --> [*]
```

### Chronologie

```mermaid
timeline
    title Project milestones
    2026-01 : Parser
    2026-02 : Layout
    2026-03 : Diagrams
```

### Carte arborescente

```mermaid
treemap-beta
"Book"
    "Chapters"
        "Guides": 40
        "Reference": 25
    "Back matter"
        "Index": 5
```

### Parcours utilisateur

```mermaid
journey
    title Publishing a topic
    section Write
      Draft the topic: 4: Author
      Add screenshots: 3: Author
    section Publish
      Review: 3: Editor
      Export PDF: 5: Author
```

### Graphique XY

```mermaid
xychart-beta
    title "Pages per release"
    x-axis [v1, v2, v3, v4]
    y-axis "Pages" 0 --> 120
    bar [40, 65, 88, 101]
    line [40, 65, 88, 101]
```
