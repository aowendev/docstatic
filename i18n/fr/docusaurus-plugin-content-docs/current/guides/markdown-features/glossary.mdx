# Termes du glossaire

Le composant **Terme du glossaire** vous permet de saisir une clé associée à un terme localisé et à une description. Le terme s'affiche souligné. Lorsque vous placez le curseur sur le terme, le curseur d'aide apparaît, et lorsque vous le survolez, la description s'affiche sous forme d'info-bulle. Sur les appareils à écran tactile, un simple tapotement sur le terme affiche une fenêtre contextuelle contenant sa définition.

## Gestion des termes du glossaire

Vous pouvez modifier la collection « Termes du glossaire » dans le CMS.

1. Cliquez sur l’icône **Ajouter** ( **+** ) pour ajouter une nouvelle **clé**.
2. Modifiez la clé, puis cliquez sur l’icône **Ajouter** ( **+** ) pour ajouter une nouvelle **Traduction**.
3. Modifiez la traduction.
4. Attribuez-lui un **code de langue**.
5. Saisissez la façon dont le **terme** doit apparaître dans le texte.
6. **Saisissez la définition.**

Le terme du glossaire utilisera la version linguistique de la page sur laquelle il est affiché. Si aucune définition n’existe, il reviendra à la langue source.

## Utilisation des termes du glossaire

1. Sélectionnez **Terme du glossaire** dans la liste **Intégrer**.
2. Modifiez le composant.
3. Saisissez la **clé**.
