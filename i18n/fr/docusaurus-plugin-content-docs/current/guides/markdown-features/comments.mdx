# Commentaires

Le composant **Commentaire** vous permet d'ajouter des commentaires visibles dans le CMS, mais pas sur la page affichée, ni même dans le code source brut.

1. Sélectionnez **Commentaire** dans la liste **Intégrer**.
2. Modifiez le composant.
3. Indiquez un **Réviseur**.
4. Saisissez un **Commentaire**.

#### Exemple

<Comment comment="This comment is invisible in the published website." reviewer="AOwenDev" />
