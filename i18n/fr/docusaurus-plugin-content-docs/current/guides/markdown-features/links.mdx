# Liens Markdown

Il existe deux façons d'ajouter un lien vers une autre page : via une URL ou un chemin d'accès au fichier.

```
- [URL path to another document](./installation)
- [file path to another document](./installation.mdx)
```

Dans le CMS, vous pouvez ajouter un lien à partir du presse-papiers en sélectionnant un passage de texte et en le collant.

Vous pouvez également surligner une partie du texte et cliquer sur l’icône « Lien » pour ajouter un chemin d’accès.

Vous pouvez aussi placer le curseur à l’endroit où vous souhaitez que le lien apparaisse, cliquer sur l’icône, puis saisir le chemin d’accès et le texte d’affichage.

Pour plus d’informations sur les liens, consultez la section <Url urlKey="docusaurus-markdown-links" /> dans la documentation de Docusaurus.
