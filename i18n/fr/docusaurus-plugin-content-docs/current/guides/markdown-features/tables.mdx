Le composant **CalsTable** prend en charge le [modèle de tableau CALS](https://www.oasis-open.org/specs/tm9901.html) utilisé par DocBook et DITA : cellules fusionnées, largeurs et alignement par colonne, ainsi qu’un contrôle précis des bordures. Un éditeur graphique de grille intégré au CMS gère la structure (fusion et division de cellules, insertion et suppression de lignes et de colonnes) ; vous n'avez donc jamais besoin de modifier manuellement les données sous-jacentes du tableau.

1. Sélectionnez **CALS Table** dans la liste **Embed**.
2. Utilisez les commandes **Cadre**, **Titre** et **Sur toute la page** situées en haut pour définir la bordure extérieure, la légende et la largeur du tableau.
3. Cliquez sur une cellule pour la sélectionner. Cliquez tout en maintenant la touche Maj enfoncée ou faites glisser pour sélectionner une plage rectangulaire de cellules.
4. Cliquez sur **Fusionner** pour fusionner les cellules sélectionnées, ou sur **Diviser** pour annuler une fusion. L’option **Fusionner** n’est disponible que lorsque la sélection forme un rectangle net qui ne traverse pas une cellule déjà fusionnée.
5. Utilisez **Insérer une ligne au-dessus/en dessous**, **Supprimer une ligne**, **Insérer une colonne à gauche/à droite** et **Supprimer une colonne** pour modifier la forme de la grille.
6. Double-cliquez sur une cellule pour modifier son contenu. Le contenu des cellules est au format Markdown ; les balises `**gras**`, `*italique*`, les liens et le code en ligne fonctionnent donc tous.
7. **Enregistrez** vos modifications.

<Admonition type="note" title="Scope">
  Each table supports one header, body and footer section with a single set of columns. DocBook's multiple-`tgroup`-per-table and nested-table (`entrytbl`) features aren't supported.
</Admonition>

#### Exemple :

<CalsTable table={{ frame: "all", title: "Release channels", tgroup: { cols: 3, colspecs: [ { colname: "c1", colwidth: "1*" }, { colname: "c2", colwidth: "1*" }, { colname: "c3", colwidth: "1*" } ], thead: { rows: [ { entries: [ { content: "Channel" }, { content: "Cadence" }, { content: "Support" } ] } ] }, tbody: { rows: [ { entries: [ { content: "Stable" }, { content: "Monthly" }, { content: "Full", morerows: 1 } ] }, { entries: [{ content: "Beta" }, { content: "Weekly" }] }, { entries: [ { content: "Nightly", namest: "c1", nameend: "c2" }, { content: "None" } ] } ] } }, pgwide: true }} />

Pour en savoir plus sur le modèle sous-jacent, consultez la [référence du modèle de tableau CALS](https://www.oasis-open.org/specs/tm9901.html) ou la [documentation sur les tableaux DocBook](https://tdg.docbook.org/tdg/5.2/cals.table.html).
