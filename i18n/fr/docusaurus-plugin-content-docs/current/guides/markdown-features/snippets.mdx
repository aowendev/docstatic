# Extraits

Le composant **Extrait** vous permet de réutiliser du contenu dans l'ensemble de votre documentation. Un extrait est un fragment de contenu pouvant être inséré dans une ou plusieurs rubriques. Lorsque vous modifiez l'extrait, ces modifications sont répercutées partout où l'extrait est utilisé. Cela peut s'avérer particulièrement utile pour les textes standardisés. Les extraits disposent de leur propre collection dans le CMS et sont regroupés dans une partie distincte du référentiel.

1. Sélectionnez le composant **Extrait** dans la liste **Intégrer**.
2. Modifiez le composant.
3. Choisissez un fichier dans la liste. Cette liste est renseignée avec tous les fichiers du dossier `/reuse/snippets/` chaque fois que vous lancez le serveur de développement ou que vous effectuez une compilation.
