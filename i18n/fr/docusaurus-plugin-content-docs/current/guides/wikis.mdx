# Wikis

Une page wiki est une page web ou de documentation conçue pour la collaboration. Elle peut être créée et modifiée en quelques minutes et est souvent utilisée pour le partage de connaissances au sein d’une équipe, ainsi que pour du contenu d’aide destiné au grand public.

Lorsque vous travaillez avec des rubriques wiki dans le CMS :

* Créez les rubriques wiki dans le dossier `/docs/wiki/`.
* Vous n’avez pas besoin d’ajouter les articles wiki à la table des matières. La barre latérale des articles wiki est générée automatiquement, en fonction de la structure des fichiers dans le dépôt.
* Les articles wiki ne contiennent pas de métadonnées.

docStatic peut associer automatiquement une catégorie à son document d’index. Un document d’index de catégorie est un document respectant la convention de nommage suivante :

Nommé `README` (sans distinction de casse) : `docs/wiki/folder/readme.mdx`.

Pour plus d’informations, consultez la section <Url urlKey="docusaurus-autogenerated" linkText={[{ lang: "en", text: "Autogenerated" }]} /> de la documentation Docusaurus.

## Créer une page wiki dans le CMS

1. Sélectionnez la collection **Pages Wiki**.
2. Cliquez sur **Ajouter un fichier**.
3. Donnez un **Titre** à votre nouvelle page wiki.
4. Saisissez le contenu.
5. Cliquez sur **Enregistrer**.
