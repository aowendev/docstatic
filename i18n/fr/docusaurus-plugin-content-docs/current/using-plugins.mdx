# Utilisation de plugins

Le noyau du générateur de sites statiques ne propose aucune fonctionnalité en soi. Toutes les fonctionnalités sont gérées par des plugins distincts : la fonctionnalité de documentation est assurée par le <Url urlKey="docusaurus-docs-plugin-api-reference" linkText={[{ lang: "fr", text: "plugin docs" }]} /> ; la fonctionnalité de blog fournie par le <Url urlKey="docusaurus-blog-plugin-api-reference" linkText={[{ lang: "fr", text: "plugin blog" }]} /> ; ou les pages individuelles fournies par le <Url urlKey="docusaurus-pages-plugin" />.

docStatic est préconfiguré pour utiliser les plugins nécessaires à la prise en charge :

* des équations mathématiques KaTeX
* la recherche Lunr
* les diagrammes Mermaid
* la documentation OpenAPI
* la documentation GraphQL

Pour plus d’informations, consultez la section <Url urlKey="docusaurus-using-plugins" linkText={[{ lang: "fr", text: "Utilisation des plugins" }]} /> dans la documentation de Docusaurus.
