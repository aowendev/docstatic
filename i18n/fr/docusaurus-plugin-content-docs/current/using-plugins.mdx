Le noyau du générateur de sites statiques ne propose aucune fonctionnalité en soi. Toutes les fonctionnalités sont gérées par des plugins distincts : la fonctionnalité de documentation est assurée par le [plugin docs](https://docusaurus.io/docs/api/plugins/@docusaurus/plugin-content-docs) ; la fonctionnalité de blog fournie par le [plugin blog](https://docusaurus.io/docs/api/plugins/@docusaurus/plugin-content-blog) ; ou les pages individuelles fournies par le [plugin pages](https://docusaurus.io/docs/api/plugins/@docusaurus/plugin-content-pages).

docStatic est préconfiguré pour utiliser les plugins nécessaires à la prise en charge :

* des équations mathématiques KaTeX
* la recherche Lunr
* les diagrammes Mermaid
* la documentation OpenAPI
* la documentation GraphQL

Pour plus d’informations, consultez la section [Utilisation des plugins](https://docusaurus.io/docs/using-plugins) dans la documentation de Docusaurus.
