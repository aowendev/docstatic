# Configuration

La configuration du site statique doc est gérée via le fichier `docusaurus.config.ts`. Pour savoir comment modifier directement ce fichier, consultez la section <Url urlKey="docusaurus-configuration" /> de la documentation Docusaurus.

Pour utiliser le CMS afin de modifier la configuration, accédez à la collection **Paramètres**. À partir de là, vous pouvez configurer les éléments suivants du site :

* **Titre**.
* **Slogan**.
* **Favicon**.
* **URL du schéma GraphQL**.
* **Mode de couleur** par défaut (foncé ou clair).
* Éléments du **pied de page**.
* **Langues**.
* **Logo**.
* Schémas **OpenAPI**.
* **Mise en évidence de la syntaxe**.
* **URL**.
* **Barre de navigation**.
* Paramètres de la **barre latérale**.
* Paramètres du **blog**.

Il existe une collection distincte intitulée **Thème** permettant de modifier la palette de couleurs et les paramètres typographiques.

## Site vs. Collections

La barre latérale du CMS se divise en deux groupes :

* **Collections** — contenu réutilisable à partir duquel vous créez de nombreux documents, tels que des articles de blog, des documents, des pages, des termes de glossaire et des pages wiki.
* **Site** — configuration unique à l’échelle du site qui ne comporte qu’un seul document : **Paramètres**, **Thème**, **Page d’accueil**, **Chatbot**, **Tableaux de bord**, **Table des matières** et le **Gestionnaire de médias** intégré.

Une collection apparaît sous **Site** plutôt que sous **Collections** lorsque son schéma définit `ui.global: true`. Cela modifie également la manière dont elle est modifiée : elle s’ouvre directement depuis la barre latérale plutôt que via une liste de documents.
