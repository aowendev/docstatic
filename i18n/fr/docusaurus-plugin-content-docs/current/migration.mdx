# Mise à jour

docStatic en étant encore à un stade précoce de développement, les modifications doivent être fusionnées individuellement à partir du dépôt principal. Cependant, les composants Node.js peuvent être mis à jour en toute sécurité en remplaçant le fichier [package.json](https://github.com/aowendev/docstatic/blob/main/package.json) par la dernière version issue du dépôt principal. Après la mise à jour, exécutez :

```shell
yarn install
```
