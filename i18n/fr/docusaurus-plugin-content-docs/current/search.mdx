# Recherche

Par défaut, docStatic est configuré pour utiliser la recherche <Url urlKey="lunr" />. Son principal avantage est qu'il s'agit d'une solution gratuite. Son principal inconvénient est que l'intégralité de l'index de recherche est téléchargée sur le navigateur de l'utilisateur ; plus votre site est volumineux, plus il est lent.

Diverses alternatives sont disponibles sous forme de plugins Docusaurus, notamment :

* Algolia (préinstallé)
* <Url urlKey="markprompt" />
* [Meilisearch](https://github.com/tauri-apps/meilisearch-docsearch)
* [Orama](https://github.com/askorama/orama/tree/main/packages/plugin-docusaurus-v3)
* <Url urlKey="markprompt" linkText={[{ lang: "fr", text: "Typesense DocSearch" }]} />

Pour plus d'informations, consultez la section <Url urlKey="docusaurus-search" /> dans la documentation Docusaurus.
