# Introduction

La barre latérale des wikis est générée automatiquement à partir de la structure des fichiers.

docStatic peut associer automatiquement une catégorie à son document d'index.

Un document d'index de catégorie est un document respectant la convention de nommage suivante :

Nommé `README` (insensible à la casse) : `docs/wiki/dossier/readme.mdx`.
