# Optimisation pour les moteurs de recherche (SEO)

docStatic prend en charge l'optimisation pour les moteurs de recherche (SEO) de différentes manières :

* Métadonnées globales
* Liens lisibles par l'utilisateur
* Méta-description des images
* Informations de recherche enrichies
* Fichier robots.txt
* Métadonnées par page
* Fichier de plan du site
* Contenu structuré

Pour plus d’informations, consultez la section [Optimisation pour les moteurs de recherche](https://docusaurus.io/docs/seo) dans la documentation de Docusaurus.
