# Internationalization

国際化（<Url urlKey="wikipedia-i18n" />）のサポートは静的サイトジェネレーターによって提供されています。詳細については、Docusaurusドキュメントの<Url urlKey="docusaurus-i18n-introduction" />を参照してください。

<Admonition type="note" title="サイドバーのラベルを翻訳するには見出し1が必要です">
  サイドバーの目次は、翻訳済みトピックのラベルを、フロントマターの `title` フィールドではなく、実際にレンダリングされる見出し1（`# タイトル`）から取得します。英語のみのサイトでは見出し1は省略可能で、フロントマターのタイトルだけで十分ですが、サイトを翻訳する場合は、すべてのトピックに、フロントマターのタイトルと完全に一致する見出し1を付けてください。そうしないと、ページの他の部分を翻訳した後も、そのトピックのサイドバー項目は英語のままになります。
</Admonition>

## CMSで翻訳済みドキュメントを編集する

1. **Translations** コレクションから、編集したいドキュメントを選択します。
2. 変更を加えます。
3. 必要に応じて **ドキュメントステータス** を **翻訳中** または **翻訳承認済み** に設定します。
4. **Save** をクリックします。
