# Internationalization

国際化（<Url urlKey="wikipedia-i18n" />）のサポートは静的サイトジェネレーターによって提供されています。詳細については、Docusaurusドキュメントの<Url urlKey="docusaurus-i18n-introduction" />を参照してください。

## CMSで翻訳済みドキュメントを編集する

1. **Translations** コレクションから、編集したいドキュメントを選択します。
2. 変更を加えます。
3. 必要に応じて **ドキュメントステータス** を **翻訳中** または **翻訳承認済み** に設定します。
4. **Save** をクリックします。
