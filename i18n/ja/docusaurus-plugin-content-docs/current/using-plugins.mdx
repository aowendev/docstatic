# プラグインの使用

静的サイトジェネレーターのコアは独自の機能を提供しません。すべての機能は個々のプラグインに委ねられています。ドキュメント機能は<Url urlKey="docusaurus-docs-plugin-api-reference" linkText={[{ lang: "ja", text: "docsプラグイン" }]} />、ブログ機能は<Url urlKey="docusaurus-blog-plugin-api-reference" linkText={[{ lang: "ja", text: "blogプラグイン" }]} />、個別ページは<Url urlKey="docusaurus-pages-plugin" />によって提供されています。

docStaticは以下をサポートするために必要なプラグインが事前設定されています。

* KaTeX数式
* Lunr検索
* Mermaidダイアグラム
* OpenAPIドキュメント
* GraphQLドキュメント

詳細については、Docusaurusドキュメントの<Url urlKey="docusaurus-using-plugins" />を参照してください。
