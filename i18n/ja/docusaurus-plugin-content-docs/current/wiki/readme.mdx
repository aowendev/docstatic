# はじめに

ウィキのサイドバーは、ファイル構造から自動的に生成されます。

docStaticは、カテゴリをそのインデックスドキュメントに自動的にリンクできます。

カテゴリインデックスドキュメントは、次のファイル名規則に従うドキュメントです。

`README`（大文字・小文字を区別しない）という名前：`docs/wiki/folder/readme.mdx`。
