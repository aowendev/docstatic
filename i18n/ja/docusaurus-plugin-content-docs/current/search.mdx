# 検索

デフォルトでは、docStaticは<Url urlKey="lunr" />検索を使用するよう設定されています。主な利点はコストゼロのソリューションであることです。主な欠点は、検索インデックス全体がユーザーのブラウザにダウンロードされるため、サイトが大きくなるほど遅くなることです。

Docusaurusプラグインとしてさまざまな代替手段が利用可能です。

* Algolia（事前インストール済み）
* <Url urlKey="markprompt" />
* [Meilisearch](https://github.com/tauri-apps/meilisearch-docsearch)
* [Orama](https://github.com/askorama/orama/tree/main/packages/plugin-docusaurus-v3)
* <Url urlKey="markprompt" linkText={[{ lang: "ja", text: "Typesense DocSearch" }]} />

詳細については、Docusaurusドキュメントの<Url urlKey="docusaurus-search" />を参照してください。
