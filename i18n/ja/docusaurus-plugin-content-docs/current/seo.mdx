# 検索エンジン最適化（SEO）

docStaticは以下のさまざまな方法で検索エンジン最適化（SEO）をサポートしています。

* グローバルメタデータ
* 人間が読みやすいリンク
* 画像のメタ説明
* リッチ検索情報
* Robotsファイル
* 単一ページのメタデータ
* サイトマップファイル
* 構造化コンテンツ

詳細については、Docusaurusドキュメントの[検索エンジン最適化](https://docusaurus.io/docs/seo)を参照してください。
