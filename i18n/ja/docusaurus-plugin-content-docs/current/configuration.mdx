# 設定

docStatic のサイト設定は、`docusaurus.config.ts` ファイルを通じて管理されます。このファイルを直接編集する方法については、Docusaurus ドキュメントの [設定](https://docusaurus.io/docs/configuration) を参照してください。

CMS を使用して設定を編集するには、**「設定」** コレクションに移動してください。ここから、サイトの以下の項目を設定できます：

* **タイトル**。
* **キャッチコピー**。
* **ファビコン**。
* **GraphQL スキーマの URL**。
* デフォルトの **カラーモード**（ダークまたはライト）。
* **フッター**の項目。
* **言語**。
* **ロゴ**。
* **OpenAPI**スキーマ。
* **シンタックスハイライト**。
* **URL**。
* **ナビゲーションバー**。
* **サイドバー**の設定。
* **ブログ**の設定。

配色やタイポグラフィの設定を変更するための、独立した**テーマ**コレクションがあります。

## サイトとコレクション

CMSのサイドバーは2つのグループに分かれています：

* **コレクション**—ブログ記事、ドキュメント、ページ、用語集、Wikiページなど、多くのドキュメントを作成するための反復可能なコンテンツ。
* **サイト**—サイト全体に適用される単一の設定で、ドキュメントは常に1つだけです。**設定**、**テーマ**、**ホームページ**、**チャットボット**、**ダッシュボード**、**目次**、および組み込みの**メディアマネージャー**などがこれにあたります。

スキーマで `ui.global: true` が設定されている場合、コレクションは **コレクション** ではなく **サイト** の下に表示されます。これにより編集方法も変わり、ドキュメント一覧を経由せずにサイドバーから直接開くようになります。
