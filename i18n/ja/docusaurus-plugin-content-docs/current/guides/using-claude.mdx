# このプロジェクトにおけるClaudeの利用

[Claude Code](https://claude.ai/code) は、AnthropicのAI搭載CLIです。このプロジェクトでは、以下で説明するタスクの開発アシスタントとして使用されています。

タスクの一覧よりも、責任の分担の方が重要です。Claudeは選択肢を提示し、その一つを主張し、コードを書きます。製品の形を決めるあらゆる決定—何を作るか、どのアプローチを取るか、何をリリースするか—はメンテナーが下します。設計上の選択がメンテナーが検討すべき影響を伴う場合、Claudeは静かに選ぶのではなく、そのトレードオフを明示することが求められます。

## 機能の設計と構築

Claudeは、孤立した変更だけでなく、機能全体に取り組みます。スキャフォールディングCLIとテンプレート同期ツール、切り替え可能なプロバイダーに対応したチャットボット、管理されたURL再利用システム、共有ダッシュボードデータレイヤーは、いずれもこの方法で開発されました。Claudeは既存のコードを調査し、設計を提案し、アプローチが合意された後に実装します。

これには設計作業も含まれます。データ構造、ビルド時と実行時の境界、新しいサブシステムの構造は、Claudeが草案を作成し、実装開始前にレビューされます。設計は頻繁に差し戻され、中には完全に却下されるものもあります。

## 手作業の自動化

Claudeは、手作業が必要となる反復的またはスクリプト化された作業を処理します。たとえば、多数のファイルにわたるフロントマターフィールドの一括更新、新しい構造に合わせたコンテンツの再フォーマット、既知のパターンに従ったボイラープレートの生成などです。これらは、作業の形が明確だが実行が煩雑なタスクです。

## Reactコンポーネントとダッシュボードの開発

ClaudeはReactコンポーネントやデータダッシュボードの作成と改善に使用されています。これには、新しいUIコンポーネントの実装、レイアウトとスタイリングの調整、TinaCMS GraphQL APIからのデータの接続が含まれます。Claudeは新しい抽象化を導入するのではなく、プロジェクト内の既存のコンポーネントパターンに従って作業します。

## CMSスキーマの定義

Claudeは、編集フォームを制御するTinaCMSのコレクションおよびテンプレート定義を作成します。これには、フィールドの検証や、他の値に応じてフィールドを表示・非表示にするルールも含まれます。

## テストの作成

Claudeはプロジェクトのテストスイートを作成し、維持します。テストは、コードがすでに述べていることを言い換えるのではなく、外部標準、仕様、または実際に生成された出力といった権威あるソースに対して動作を検証することが求められます。

## バグの追跡

Claudeは、関連するコードを読み込み、最近の変更を確認し、原因を推論することで、バグの原因を絞り込むのに役立ちます。複数のファイルにまたがるバグや、設定と動作のクロスリファレンスが必要なバグに特に有用です。

## スタイルルールの作成

ClaudeはdocStaticスタイルセットのValeルールを作成するために使用されています。これには、新しいルールの作成、サンプルコンテンツへのテスト、誤検出を減らすためのパターンの改善が含まれます。ルールはドキュメントと並んで `.vale/styles/docStatic/` にコミットされます。

## 情報アーキテクチャの維持

Claudeはドキュメントセットの情報アーキテクチャの維持を支援します。タクソノミー、タグ、ページ構造をレビューして、一貫した分類と論理的なナビゲーションを確保します。これはコンテンツレビューと並行して実行される継続的なタスクです。

## コンテンツの健全性チェック

Claudeは、事実の一貫性、構造的なギャップ、論理的な流れについてドキュメントをレビューします。これは軽量なチェックであり、正式な編集レビューを置き換えるものではありませんが、コンテンツがレビュアーに届く前に明らかな問題を発見するのに役立ちます。

## ドキュメントの草稿作成

Claudeがドキュメントページの初稿を作成し、その後人間の著者がレビューして編集することがあります。草稿は出発点として扱われ、完成したコンテンツとは見なされません。

<Admonition type="note" title="変更の検証">
  作業が完了したとみなされる前に、Claudeはコードの変更に対して `yarn lint`（Biome）を、ドキュメントの変更に対して `vale` を実行し、どちらかのツールが指摘した問題を修正します。
</Admonition>

<Admonition type="note" title="AIの関与範囲">
  docStaticのコンセプト、製品の方向性、優先順位はメンテナーが決定します。Claudeはその方向性の中で個々の機能の設計と実装に貢献し、その作業は統合される前にレビューされます。本稿執筆時点で、Claudeはコミットの約6パーセントの共同作成者となっています。
</Admonition>
