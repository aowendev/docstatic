# URLs

**URL** コンポーネントを使用すると、外部リンクをハードコーディングする代わりに、キーで参照できます。各キーは言語ごとにURLに対応しているため、訪問者は常にその言語に適したバージョンの遷移先にたどり着きます。また、移動または切れたリンクは、どれだけ多くのドキュメントで参照されていても、1か所を修正するだけで済みます。

## URLの管理

URLコレクションはCMSで編集できます。

1. **追加** アイコン（ **+** ）をクリックして新しい **キー** を追加します。
2. **URL（言語別）** で **追加** アイコンをクリックし、リンクがサポートする各言語の **翻訳** を追加します。**言語コード** と遷移先の **URL** を入力します。
3. **デフォルトのリンクテキスト（言語別）** で、各言語の **翻訳** を追加し、`<Url>` の使用箇所が独自のテキストを指定しない場合に表示するテキストを入力します。

## URLの使用

1. **埋め込み** リストから **URL Link** を選択します。
2. URLコレクション内のエントリに対応する **URLキー** を入力します。
3. 必要に応じて、この特定の使用箇所についてキーのデフォルトテキストを上書きする **リンクテキスト** の翻訳を追加します。同じキーは、異なる文言で複数の場所に使用できます。

<Admonition type="caution" title="リンクテキストは機械翻訳されていません">
  通常の文章とは異なり、`<Url>` の「リンクテキスト」は自動翻訳の対象にはなりません。ドキュメントが翻訳される際、このコンポーネント全体は、どの言語においても記述されたままの状態で完全に保持されます。リンクテキストを追加する場合は、そのリンクを最初に追加したドキュメント内で、サポートされているすべての言語について同時に記入してください。 その時点で省略された言語は、誰かがソースを編集して手動で追加するまで、欠落したままとなります。

  特定の使用例で独自の文言が必要ない場合は、リンクテキストを空欄のままにしておくと、代わりにキーの「デフォルトのリンクテキスト」が使用されます。このテキストは、URLコレクション内で通常の方法で一度だけ翻訳されます。
</Admonition>

#### 例

<Url urlKey="docusaurus-website" />

## リンクの状態の確認

URLコレクションには、ここに保存されているURLと、ドキュメント内にまだハードコーディングされている外部リンク（URLコレクションにまだ登録されていないものを含む）の両方を報告する **リンクの状態** ダッシュボードも含まれています。これにより、それらを見つけて一元化できます。詳細については、[Dashboards](/docs/guides/dashboards) を参照してください。
