# CALS Tables

**CalsTable** コンポーネントは、DocBook や DITA で使用される <Url urlKey="cals-table-model" /> の機能をサポートしています。具体的には、セルの結合、列ごとの幅や配置の設定、および詳細な境界線の制御が可能です。 CMS内のグラフィカルなグリッドエディタが、セルの結合や分割、行や列の挿入・削除、セルや列の配置といった構造の操作を処理するため、基になるテーブルデータを手作業で編集する必要は一切ありません。

1. **Embed**リストから**CALS Table**を選択します。
2. 上部の **Frame**、**Title**、**Page-wide** コントロールを使用して、表の外枠、キャプション、幅を設定します。
3. セルをクリックして選択します。Shift キーを押しながらクリックするか、ドラッグして、矩形のセル範囲を選択します。
4. **結合**をクリックして選択したセルを結合するか、**分割**をクリックして結合を解除します。**結合**は、選択範囲が既存の結合セルを横切らない、完全な長方形の場合にのみ有効になります。
5. **行を上に/下に挿入**、**行を削除**、**列を左/右に挿入**、**列を削除**を使用して、グリッドの形状を変更します。
6. **セルの配置**、**セルの垂直方向の配置**、**列の配置**を使用して、選択したセルとその列の配置方法を設定します。
7. セルをダブルクリックして内容を編集します。セルの内容は Markdown 形式であるため、`**太字**`、`*斜体*`、リンク、インラインコードがすべて使用可能です。セル内で新しい行を始めるには、Enterキーを押してください。
8. 変更内容を**保存**します。

<Admonition type="note" title="適用範囲">
  各テーブルは、1つのヘッダー、ボディ、フッターセクションと、1組の列をサポートしています。DocBookの「1つのテーブルにつき複数の`tgroup`」や「ネストされたテーブル（`entrytbl`）」といった機能はサポートされていません。
</Admonition>

## セルの配置

CALSは、セルの配置を、設定を行う3つの場所のうち最初のもの（セル、次にそのセルが属するspan、そしてその列）から取得します。エディタは、この3つのうち「セル」と「列」の2つを記述します：

* **セルの配置** は、選択したセルの水平方向の配置を設定します。
* **セルの垂直方向の配置**は、選択したセルの縦方向の配置を設定します。
* **列の配置** は、選択された列内のすべてのセルの水平方向の配置を設定します。

**継承**を選択すると、設定が保存されるのではなくクリアされるため、セルは列の設定を、列はサイトのデフォルト設定を適用します。

このデフォルトを設定するには、コレクションリストから**「設定」**を選択し、**「CALSテーブル」**を開き、**「セルの配置」**を選択します。 これは、サイト上のすべてのCALSテーブル（見出しを含む）に適用されますが、独自の配置が設定されていないセルにのみ適用されます。セルまたは列で設定された配置は、常にこの設定よりも優先されます。**ブラウザのデフォルト**では、見出しは中央揃え、本文のセルは左揃えになります。

## 表での変数の使用

セル、見出し、および表のタイトルには、いずれも [変数](variables)] を含めることができ、これらは表示されるページの言語に応じて展開されます。

1. セルを選択し、**「セル変数」**リストから選択して、そのセルに変数を追加します。
2. キャプションに変数を挿入するには、**タイトル**フィールドの横にあるリストから選択してください。

どちらのリストも、変数をテキストの最後に追加するため、別の場所に配置したい場合は、後でセルまたはタイトルを編集してください。タイトルにはMarkdownも使用できるため、`**太字**`やリンクもそこで機能します。

<Admonition type="note" title="注記">
  キーがもはや存在しない変数は、段落の中でそう記述されるのと同じように、その場でその旨を示します：

  ```
  set_key NOT FOUND
  ```

  ビルドは依然として成功するため、キーを1つ間違えてもサイトのプレビューを行うことは可能です。
</Admonition>

#### 例：

<CalsTable table={{ frame: "all", title: "Release channels", tgroup: { cols: 3, colspecs: [ { colname: "c1", colwidth: "1*" }, { colname: "c2", colwidth: "1*" }, { colname: "c3", colwidth: "1*" } ], thead: { rows: [ { entries: [ { content: "Channel" }, { content: "Cadence" }, { content: "Support" } ] } ] }, tbody: { rows: [ { entries: [ { content: "Stable" }, { content: "Monthly" }, { content: "Full", morerows: 1 } ] }, { entries: [{ content: "Beta" }, { content: "Weekly" }] }, { entries: [ { content: "Nightly", namest: "c1", nameend: "c2" }, { content: "None" } ] } ] } }, pgwide: true }} />

基盤となるモデルの詳細については、<Url urlKey="cals-table-model" linkText={[{ lang: "ja", text: "CALS テーブルモデルリファレンス" }]} /> または [DocBook テーブルのドキュメント](https://tdg.docbook.org/tdg/5.2/cals.table.html) を参照してください。
