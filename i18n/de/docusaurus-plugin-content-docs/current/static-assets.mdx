Statische Assets sind Dateien, die keinen Code enthalten und direkt in die Build-Ausgabe kopiert werden. Dazu gehören Bilder, Stylesheets, Favicons, Schriftarten und so weiter.

Sie sollten diese Assets im Ordner `static` ablegen. Jede Datei, die Sie in diesen Ordner legen, wird unter Beibehaltung der Ordnerhierarchie in das Stammverzeichnis des generierten Build-Ordners kopiert. Wenn Sie beispielsweise eine Datei namens `sun.jpg` in den Ordner `static` einfügen, wird sie nach `build/sun.jpg` kopiert.

Das bedeutet:

* Bei einer Website mit `baseUrl: '/'` wird das Bild `/static/img/sun.jpg` unter `/img/sun.jpg` bereitgestellt.
* Bei einer Website mit `baseUrl: '/subpath/'` wird das Bild `/static/img/sun.jpg` unter `/subpath/img/sun.jpg` bereitgestellt.

## Verweisen auf Ihre statischen Assets

### Im CMS

1. Fügen Sie einen Link ein.
2. Geben Sie den absoluten Pfad ein, zum Beispiel /files/note.docx.
3. Geben Sie den anzuzeigenden Text ein.

### In Markdown

```markdown
You write a link like this: [Download this document](/files/note.docx)

Docusaurus changes that to: <a href={require('static/files/note.docx')}>Download this document</a>
```

Weitere Informationen finden Sie unter [Statische Assets](https://docusaurus.io/docs/static-assets) in der Docusaurus-Dokumentation.
