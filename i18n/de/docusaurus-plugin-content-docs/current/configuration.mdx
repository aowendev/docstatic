# Konfiguration

Die Konfiguration der statischen Website erfolgt über die Datei `docusaurus.config.ts`. Informationen zum direkten Bearbeiten dieser Datei finden Sie unter <Url urlKey="docusaurus-configuration" /> in der Docusaurus-Dokumentation.

Um die Konfiguration über das CMS zu bearbeiten, navigieren Sie zur Sammlung **Einstellungen**. Von hier aus können Sie folgende Einstellungen der Website konfigurieren:

* **Titel**.
* **Slogan**.
* **Favicon**.
* **URL des GraphQL-Schemas**.
* Standard-**Farbmodus** (dunkel oder hell).
* **Fußzeilen**-Elemente.
* **Sprachen**.
* **Logo**.
* **OpenAPI**-Schemas.
* **Syntaxhervorhebung**.
* **URL**.
* **Navigationsleiste**.
* **Seitenleiste**-Einstellungen.
* **Blog**-Einstellungen.

Es gibt eine separate **Theme**-Sammlung zum Ändern des Farbschemas und der Typografie-Einstellungen.

## Websites und Sammlungen

Die CMS-Seitenleiste ist in zwei Gruppen unterteilt:

* **Sammlungen**: Wiederverwendbare Inhalte, aus denen Sie viele Dokumente erstellen, wie z. B. Blog-Artikel, Dokumente, Seiten, Glossarbegriffe und Wiki-Seiten.
* **Website**: Eine einmalige, websiteweite Konfiguration, die immer nur ein Dokument enthält: **Einstellungen**, **Design**, **Startseite**, **Chatbot**, **Dashboards**, **Inhaltsverzeichnis** und den integrierten **Medienmanager**.

Eine Sammlung wird unter **Website** statt unter **Sammlungen** angezeigt, wenn in ihrem Schema `ui.global: true` festgelegt ist. Dadurch ändert sich auch die Art der Bearbeitung: Die Sammlung wird direkt über die Seitenleiste geöffnet, anstatt über eine Dokumentliste.
