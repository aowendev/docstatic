# Hinweise

Mit der Komponente **Hinweise** können Sie formatierte Hinweise einfügen.

1. Wählen Sie **Hinweis** aus der Liste **Einbetten** aus.
2. Bearbeiten Sie die Komponente und wählen Sie einen **Typ** aus (**Hinweis**, **Tipp**, **Info**, **Achtung** oder **Warnung**).
3. Geben Sie einen **Titel** ein.
4. Geben Sie den **Inhalt** ein.

#### Beispiele:

<Admonition type="note" title="Hinweis">
  Verwenden Sie Hinweise in den Anmerkungen für ergänzende Informationen.
</Admonition>

<Admonition type="tip" title="Tipp">
  Verwenden Sie „Tipp“-Hinweise, um Ratschläge zu geben, die man getrost ignorieren kann.
</Admonition>

<Admonition type="info" title="Info">
  Verwenden Sie Info-Hinweise für Informationen, die so wichtig sind, dass sie sich vom restlichen Text abheben müssen.
</Admonition>

<Admonition type="caution" title="Achtung">
  Verwenden Sie Warnhinweise, wenn etwas die Ausführung einer beabsichtigten Aktion verhindern könnte.
</Admonition>

<Admonition type="danger" title="Warnung">
  Verwenden Sie Warnhinweise, wenn die Gefahr von Verletzungen, Sicherheitsverletzungen oder Datenverlusten besteht.
</Admonition>
