# Diagramme

Diagramme können mithilfe von <Url urlKey="mermaid" /> in einem Code-Block dargestellt werden.

## Verwendung

Das CMS unterstützt die Bearbeitung von Mermaid-Diagrammen direkt.

1. Klicken Sie auf das **Mermaid**-Symbol.
2. Geben Sie den Markdown-Code in das Feld ein.

Klicken Sie auf **Vorschau**, um Ihr Diagramm anzuzeigen.

#### Beispiel:

```mermaid
graph TD;
    A-->B;
    A-->C;
    B-->D;
    C-->D;
```

<Admonition type="note" title="Hinweis">
  Derzeit werden zenUML-Diagramme nicht unterstützt, und Mindmap-Diagramme können zu ungewöhnlichem Verhalten führen. Nicht alle Diagrammtypen können im CMS in der Vorschau angezeigt werden.
</Admonition>

Weitere Informationen finden Sie unter [Mermaid](https://tina.io/docs/reference/rich-text-usage/mermaid) in der TinaCMS-Dokumentation.

Informationen zur Gestaltung von Mermaid-Diagrammen finden Sie unter <Url urlKey="docusaurus-diagrams" /> in der Docusaurus-Dokumentation.

## Beispiele

### Architekturdiagramm

```mermaid
architecture-beta
    group site(cloud)[Site]
    service cms(server)[CMS] in site
    service store(database)[Content] in site
    service pdf(server)[Exporter] in site
    cms:R --> L:store
    store:R --> L:pdf
```

### Blockdiagramm

```mermaid
block-beta
    columns 3
    Parser["Parser"] Resolver["Resolver"] Composer["Composer"]
    space:3
    PDF["PDF"]:3
```

### C4-Kontextdiagramm

```mermaid
C4Context
    title Publishing system
    Person(author, "Author", "Writes topics")
    System(cms, "CMS", "Edits content")
    System(exporter, "PDF exporter", "Produces books")
    Rel(author, cms, "Edits")
    Rel(cms, exporter, "Feeds")
```

### Klassendiagramm

```mermaid
classDiagram
    class Chapter {
        +string Title
        +int Depth
        +VisibleBlocks()
    }
    class Book {
        +Compose()
    }
    Book "1" *-- "many" Chapter : contains
```

### Entity-Relationship-Diagramm

```mermaid
erDiagram
    TOPIC ||--o{ TAG : carries
    TOPIC ||--o{ SNIPPET : includes
    TOPIC {
        string title
        bool published
    }
```

### Flussdiagramm

```mermaid
flowchart TD
    Start([Start]) --> Input[/Read topic/]
    Input --> Check{Valid?}
    Check -->|Yes| Render[Render PDF]
    Check -->|No| Warn[Warn and continue]
    Render --> Done([Done])
    Warn --> Done
```

### Gantt-Diagramm

```mermaid

    section Content
    Draft topics      :a1, 2026-01-06, 10d
    Review            :after a1, 5d
    section Build
    Export PDFs       :2026-01-26, 3d
```

```mermaid
    element exporter {
        type: application
    }
    exporter - satisfies -> print_fidelity
```
