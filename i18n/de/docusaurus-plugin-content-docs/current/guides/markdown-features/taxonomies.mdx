# Taxonomie-Tags

Mit Taxonomie-Tags können Sie eine <Url urlKey="wikipedia-information-architecture" /> auf die Inhalte Ihrer Website anwenden. Dies sollte auf alle von Ihnen genutzten Dokumentationsplattformen angewendet werden, wie beispielsweise Bug-Tracking-Systeme und Wikis. Die restriktivsten Anforderungen an Tags, auf die Sie wahrscheinlich stoßen werden, gelten für flache (nicht-hierarchische) Systeme, die nur Kleinbuchstaben und Unterstriche (`_`) ohne Leerzeichen unterstützen.

docStatic wendet eine dreistufige Hierarchie auf Taxonomie-Tags an. Um zu verhindern, dass die Tags unverhältnismäßig lang werden, ist die Verschachtelung auf eine maximale Tiefe von drei Ebenen begrenzt. In einigen Fällen erfordert dies eine Abflachung der Struktur (beispielsweise ist `regions_europe_uk_scotland` zwar logisch, hat aber vier Ebenen und muss daher als `regions_uk_scotland` strukturiert werden).

Bei der Gestaltung einer dreistufigen Informationsarchitektur wird empfohlen, etwa zehn Kategorien der obersten Ebene, sieben Kategorien der mittleren Ebene und so viele Kategorien der untersten Ebene wie nötig anzustreben. Sie sollten Akronyme und Abkürzungen ausschreiben und Redundanzen vermeiden.

## Taxonomie-Tags bearbeiten

1. Fügen Sie in der Sammlung **Taxonomien** eine Taxonomie **hinzu**.
2. Geben Sie ihr ein **Tag**, das ausschließlich aus Kleinbuchstaben besteht.
3. Fügen Sie gegebenenfalls **Unterelemente** hinzu und vergeben Sie ihnen ein Tag, das mit dem übergeordneten Tag beginnt, gefolgt von einem Unterstrich.
4. Fügen Sie für jedes Unterelement gegebenenfalls weitere Unterelemente hinzu.

<Admonition type="note" title="Note">
  You can enter tags without the preceding tag name and an underscore, but if you do when adding them to a topic, they will be presented as a flat list.
</Admonition>
