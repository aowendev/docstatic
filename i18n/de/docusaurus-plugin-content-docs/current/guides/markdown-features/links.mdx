# Markdown-Links

Es gibt zwei Möglichkeiten, einen Link zu einer anderen Seite hinzuzufügen: über einen URL-Pfad oder einen Dateipfad.

```
- [URL path to another document](./installation)
- [file path to another document](./installation.mdx)
```

Im CMS können Sie einen Link aus der Zwischenablage einfügen, indem Sie einen Textabschnitt markieren und einfügen.

Sie können auch einen Textabschnitt markieren und auf das Link-Symbol klicken, um einen Pfad hinzuzufügen.

Oder Sie setzen den Cursor an die Stelle, an der der Link erscheinen soll, klicken auf das Symbol und geben den Pfad sowie den Anzeigetext ein.

Weitere Informationen zu Links finden Sie unter <Url urlKey="docusaurus-markdown-links" /> in der Docusaurus-Dokumentation.
