# Abbildungen

Mit der Komponente **Abbildung** können Sie einem Thema Bilder mit Bildunterschriften hinzufügen. Wenn ein Benutzer auf eine Abbildung klickt, wird sie in maximaler Vergrößerung in einer Lightbox angezeigt.

1. Wählen Sie **Abbildung** aus der Liste **Einbetten**.
2. Bearbeiten Sie die Komponente.
3. Wählen Sie ein Bild aus dem Medienmanager aus.
4. Geben Sie eine **Bildunterschrift** ein. Diese wird auch als Alt-Text-Element für Bildschirmleser verwendet.
5. (Optional) Geben Sie eine Größe ein.
