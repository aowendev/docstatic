# Fußnoten

Es gibt eine Markdown-Erweiterung, die Fußnoten bereitstellt, deren Umsetzung jedoch uneinheitlich ist und die den Inhalt von der Nummer trennt. Zum Beispiel:

```markdown
Markdown ist eine leichtgewichtige Auszeichnungssprache[^1], die von John Gruber[^2] entwickelt wurde und heute beim Schreiben weit verbreitet ist[^3].

[^1]: Markdown verwendet eine einfache Syntax, um Textformatierungen zu erzielen.
[^2]: John Gruber hat Markdown 2004 entwickelt.
[^3]: Viele Plattformen wie GitHub, Stack Overflow und Blog-Plattformen unterstützen Markdown.
```

In docStatic würde dies so dargestellt:

```markdown
Markdown ist eine leichtgewichtige Auszeichnungssprache<Footnote summary="1"> Markdown verwendet eine einfache Syntax, um Textformatierungen zu erzielen.</Footnote>
entwickelt von John Gruber<Footnote summary="2">John Gruber hat Markdown 2004 entwickelt.</Footnote>,
heute beim Schreiben weit verbreitet<Footnote summary="3">Viele Plattformen wie GitHub, Stack Overflow und Blog-Plattformen unterstützen Markdown.</Footnote>.
```

Mit der Komponente **Fußnoten** können Sie Ihrem Text Inline-Fußnoten hinzufügen.

1. Wählen Sie **Fußnoten** aus der Liste **Einbetten** aus.
2. Bearbeiten Sie die Komponente.
3. Geben Sie eine **Zusammenfassung** ein.
4. Geben Sie die **Fußnote** ein.

#### Beispiel

Markdown ist eine leichtgewichtige Auszeichnungssprache<Footnote summary="1"> Markdown verwendet eine einfache Syntax, um Textformatierungen zu erzielen.</Footnote> entwickelt von John Gruber<Footnote summary="2">John Gruber hat Markdown 2004 entwickelt.</Footnote>, heute beim Schreiben weit verbreitet<Footnote summary="3">Viele Plattformen wie GitHub, Stack Overflow und Blog-Plattformen unterstützen Markdown.</Footnote>.

Fußnoten werden in der Reihenfolge nummeriert, in der sie erscheinen, und die Notizen selbst werden am Seitenende gesammelt. Die Nummerierung wird beim Erstellen der Website berechnet, sodass die Nummern und die Notizen bereits in der ausgelieferten Seite enthalten sind, statt erst vom Browser zusammengesetzt zu werden.

## Eine Fußnote wiederholen

Zwei Fußnoten mit demselben Inhalt sind dieselbe Notiz. Sie teilen sich eine Nummer und erscheinen nur einmal am Seitenende, sodass ein Punkt, den Sie zweimal machen möchten, die Liste nicht unnötig füllt.

<Admonition type="info" title="Beispiel">
  Markdown wird von vielen Plattformen unterstützt<Footnote summary="Plattformunterstützung">Viele Plattformen, darunter GitHub und Stack Overflow, unterstützen Markdown.</Footnote>, ebenso seine Tabellensyntax<Footnote summary="Plattformunterstützung">Viele Plattformen, darunter GitHub und Stack Overflow, unterstützen Markdown.</Footnote>.
</Admonition>

Beide Markierungen oben verweisen auf dieselbe Notiz, weil ihr Text identisch ist. Ändern Sie eine davon, und sie wird zu einer eigenen Notiz.

## Fußnoten und Zitate

Bei einem **Notiz**-Zitierstil ist ein Zitat ebenfalls eine Fußnote, und Zitate teilen sich dieselbe Nummerierungsfolge. Unter [Zitate](./citations.mdx) erfahren Sie, wie das funktioniert und wie es aussieht.
