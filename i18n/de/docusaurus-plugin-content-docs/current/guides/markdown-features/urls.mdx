# URLs

Die Komponente **URL** ermöglicht es Ihnen, auf einen externen Link über einen Schlüssel zu verweisen, statt ihn fest zu codieren. Jeder Schlüssel ordnet einer Sprache eine URL zu, sodass ein Besucher immer auf der sprachlich passenden Version des Ziels landet, und ein Link, der sich ändert oder nicht mehr funktioniert, muss nur an einer Stelle korrigiert werden, unabhängig davon, wie viele Dokumente ihn referenzieren.

## Verwalten von URLs

Sie können die Sammlung „URLs" im CMS bearbeiten.

1. Klicken Sie auf das Symbol **Hinzufügen** ( **+** ), um einen neuen **Schlüssel** hinzuzufügen.
2. Klicken Sie unter **URL (pro Sprache)** auf das Symbol **Hinzufügen**, um für jede Sprache, die der Link unterstützen soll, eine **Übersetzung** hinzuzufügen. Geben Sie einen **Sprachcode** und die Ziel-**URL** an.
3. Fügen Sie unter **Standard-Linktext (pro Sprache)** für jede Sprache eine **Übersetzung** hinzu und legen Sie den Text fest, den eine `<Url>`-Verwendung anzeigen soll, wenn sie keinen eigenen angibt.

## Verwendung von URLs

1. Wählen Sie **URL Link** aus der Liste **Einbetten** aus.
2. Geben Sie den **URL-Schlüssel** ein, der einem Eintrag in der URLs-Sammlung entspricht.
3. Fügen Sie optional Übersetzungen für den **Linktext** hinzu, um den Standardtext des Schlüssels für diese bestimmte Verwendung zu überschreiben – derselbe Schlüssel kann an verschiedenen Stellen mit unterschiedlichem Wortlaut verwendet werden.

<Admonition type="caution" title="Der Linktext wurde nicht maschinell übersetzt">
  Im Gegensatz zu gewöhnlicher Prosa wird der Linktext einer `<Url>`-Verwendung niemals einer automatischen Übersetzung unterzogen – die gesamte Komponente bleibt bei der Übersetzung eines Dokuments in jeder Sprache genau so erhalten, wie sie geschrieben wurde. Wenn Sie Linktext hinzufügen, geben Sie diesen gleichzeitig in allen unterstützten Sprachen in dem Dokument ein, in dem Sie den Link zum ersten Mal einfügen. Eine Sprache, die an dieser Stelle ausgelassen wird, bleibt so lange unberücksichtigt, bis jemand die Quelle bearbeitet und sie manuell hinzufügt.

  Wenn Sie für eine bestimmte Verwendung keinen benutzerdefinierten Wortlaut benötigen, lassen Sie den Linktext leer; stattdessen wird der Standard-Linktext des Schlüssels verwendet – dieser Text wird auf die übliche Weise einmalig in der URLs-Sammlung übersetzt.
</Admonition>

## Überprüfung des Linkzustands

Die URLs-Sammlung beherbergt außerdem das Dashboard **Linkzustand**, das sowohl über die hier gespeicherten URLs als auch über alle externen Links berichtet, die noch direkt in Ihren Dokumenten fest codiert sind – einschließlich derer, die noch nicht in der URLs-Sammlung enthalten sind, damit Sie sie finden und zentralisieren können. Einzelheiten finden Sie unter [Dashboards](/docs/guides/dashboards).
