# Kommentare

Mit der Komponente **Kommentar** können Sie Kommentare hinzufügen, die im CMS sichtbar sind, jedoch nicht auf der gerenderten Seite – auch nicht im Quellcode.

1. Wählen Sie **Kommentar** aus der Liste **Einbetten** aus.
2. Bearbeiten Sie die Komponente.
3. Geben Sie einen **Prüfer** ein.
4. Geben Sie einen **Kommentar** ein.
