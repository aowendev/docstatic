# Tabs

Mit der Komponente **Registerkarten** können Sie Ihrem Thema Inhalte mit Registerkarten hinzufügen.

1. Wählen Sie **Tabs** aus der Liste **Einbetten** aus.
2. Bearbeiten Sie die Komponente.
3. Für jede Registerkarte:
   1. Wählen Sie **Registerkartenelement** aus der Liste **Einbetten** aus.
   2. Geben Sie einen **Wert** ein.
   3. Geben Sie einen **Titel** ein.
   4. Geben Sie den **Inhalt** ein.
   5. (Optional) Legen Sie die Registerkarte als **Standard** fest.
4. **Speichern** Sie Ihre Änderungen.

<Admonition type="danger" title="Warnung">
  Beim Bearbeiten von Registerkarten kann es vorkommen, dass das CMS den Kontext verliert. Sie sollten daher regelmäßig speichern. Es kann vorkommen, dass das CMS den Kontext der Registerkarte nicht mehr finden kann. Klicken Sie in diesem Fall auf das Symbol **Raw Markdown** und nehmen Sie die Änderungen direkt im Markdown vor. Speichern Sie anschließend und kehren Sie zum Rich-Text-Editor zurück.
</Admonition>

#### Beispiel:

<Tabs>
  <TabItem label="Apple" value="apple">
    This is an apple 🍎
  </TabItem>

  <TabItem label="Orange" value="orange">
    This is an orange 🍊
  </TabItem>

  <TabItem label="Banana" value="banana">
    This is a banana 🍌
  </TabItem>
</Tabs>
