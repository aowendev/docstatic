# Wikis

Eine Wiki-Seite ist eine Web- bzw. Dokumentationsseite, die für die Zusammenarbeit konzipiert ist. Sie lässt sich innerhalb weniger Minuten erstellen und bearbeiten und wird häufig sowohl für den internen Wissensaustausch im Team als auch für öffentlich zugängliche Hilfeinhalte genutzt.

Bei der Arbeit mit Wiki-Themen im CMS:

* Erstellen Sie Wiki-Themen im Ordner `/docs/wiki/`.
* Sie müssen die Wiki-Themen nicht zum Inhaltsverzeichnis hinzufügen. Die Seitenleiste für Wiki-Themen wird automatisch auf Basis der Dateistruktur im Repo generiert.
* Wiki-Themen enthalten keine Metadaten.

docStatic kann automatisch eine Kategorie mit ihrem Indexdokument verknüpfen. Ein Kategorie-Indexdokument ist ein Dokument, das dieser Dateinamenskonvention folgt:

Benannt als `README` (Groß-/Kleinschreibung spielt keine Rolle): `docs/wiki/folder/readme.mdx`.

Weitere Informationen finden Sie unter [Autogenerated](https://docusaurus.io/docs/sidebar/autogenerated#autogenerated-sidebar-metadata) in der Docusaurus-Dokumentation.

## Eine Wiki-Seite im CMS erstellen

1. Wählen Sie die Sammlung **Wiki-Seiten** aus.
2. Klicken Sie auf **Datei hinzufügen**.<Figure img="/img/docs/wiki-pages-add-wiki.png" caption="TinaCMS. A callout highlights the Wiki option and the Add file option." />
3. Geben Sie Ihrer neuen Wiki-Seite einen **Titel**.
4. Geben Sie den Inhalt ein.
5. Klicken Sie auf **Speichern**.
