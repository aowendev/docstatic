# Blog

Mit der Blog-Funktion können Sie Artikel mit Zeitstempel erstellen.

<Admonition type="info" title="Info">
  Refer to <Url urlKey="docusaurus-blog-plugin-api-reference" /> in the Docusaurus documentation for an exhaustive list of options.
</Admonition>

1. Klicken Sie im CMS in der Sammlung **Blog-Artikel** auf **Datei hinzufügen**.
2. Geben Sie einen **Titel** ein.
3. Fügen Sie gegebenenfalls **Autoren** hinzu. Bearbeiten Sie für jeden Autor die Komponente und fügen Sie Folgendes hinzu:
   1. Den **Namen**.
   2. Den **Titel**.
   3. Eine **URL**.
   4. Eine **Bild-URL**.
4. Wählen Sie das **Veröffentlichungsdatum** aus. In der Produktionsumgebung werden Artikel mit einem späteren Veröffentlichungsdatum erst angezeigt, wenn die Website neu generiert wird. Sie werden jedoch angezeigt, wenn der Entwicklungsserver ausgeführt wird (`npm run dev`).
5. (Optional) Fügen Sie gegebenenfalls **Tags** aus der Taxonomie hinzu.
6. Geben Sie den Inhalt ein.
7. Klicken Sie auf **Speichern**.

Weitere Informationen finden Sie im <Url urlKey="docusaurus-blog" /> der Docusaurus-Dokumentation.
