# Benachrichtigungen

docStatic nutzt [GitHub Actions](https://docs.github.com/en/actions), um Workflow-Benachrichtigungen zu versenden. Beispielbenachrichtigungen für die Überprüfung und Übersetzung sind im Ordner `.github/workflows/` enthalten. Um diese zu aktivieren, sind einige Konfigurationen in GitHub erforderlich. Sie können diese auch als Ausgangspunkt nutzen, um Ihre eigenen benutzerdefinierten Benachrichtigungen zu entwickeln.

## E-Mail

Die Aktionen `email-review.yml` und `email-translate.yml` werden ausgelöst, wenn entweder das Tag „review“ oder das Tag „translate“ für eine Markdown-Datei im Hauptzweig gesetzt wird. Um sie zu verwenden, fügen Sie Ihrem Repository diese [Geheimnisse](https://docs.github.com/en/actions/how-tos/write-workflows/choose-what-workflows-do/use-secrets) hinzu:

* `SMTP_SERVER`
* `SMTP_PORT`
* `SMTP_USERNAME`
* `SMTP_PASSWORD`
* `NOTIFY_EMAIL_TO`
* `NOTIFY_EMAIL_FROM`

Diese Informationen erhalten Sie von Ihrem E-Mail-Anbieter. Zum Beispiel:

* [iCloud](https://support.apple.com/en-us/102525) (erfordert ein [App-spezifisches Passwort)](https://support.apple.com/en-us/102654).
* [Outlook](https://support.microsoft.com/en-us/office/pop-imap-and-smtp-settings-for-outlook-com-d088b986-291d-42b8-9564-9c414e2aa040)

## Slack

Die Aktionen `slack-review.yml` und `slack-translate.yml` verwenden dieselben Auslöser wie die E-Mail-Versionen. Um sie zu nutzen, fügen Sie Ihre Slack-Webhook-URL als Geheimnis mit dem Namen `SLACK_WEBHOOK_URL` hinzu. Weitere Informationen finden Sie unter [Senden von Nachrichten mithilfe von eingehenden Webhooks](https://docs.slack.dev/messaging/sending-messages-using-incoming-webhooks/) in der Slack-Dokumentation.

## Teams

Die Aktionen `teams-review.yml` und `teams-translate.yml` funktionieren wie die Slack-Versionen. Microsoft stellt die App **Incoming Webhooks** für Teams ab Dezember 2025 ein, doch derzeit gibt es keine öffentlich verfügbare GitHub-Methode zum Senden von Adaptive Cards an Workflows. Als Workaround kann man `curl` verwenden:

```yaml
- name: Send Teams test notification
  run: |
    curl --ssl-no-revoke -X POST \
    --location ${{ secrets.MS_TEAMS_HTTP_POST_URL }} \
    --header 'Content-Type: application/json' \
    --data '{ \
      "type": "message", \
      "attachments": [{ \
        "contentType": "application/vnd.microsoft.card.adaptive", \
        "content": { \
          "$schema": "http://adaptivecards.io/schemas/adaptive-card.json", \
          "type": "AdaptiveCard", \
          "version": "1.3", \
          "body": [ { \
            "type": "TextBlock", \
            "text": "This is a test notification from GitHub Actions (Teams).", \
            "wrap": true }]}}]}'
```

1. Gehen Sie in Teams zu dem Kanal, an den Sie Nachrichten senden möchten, klicken Sie auf die Ellipse (**…**) und wählen Sie **Workflows** aus.
2. Klicken Sie auf **Verwalten**.
3. Klicken Sie auf **Neuer Flow**.
4. Suchen Sie in den Vorlagen nach Webhooks und klicken Sie auf **Webhook-Benachrichtigungen an einen Kanal senden**.
5. (Optional) Bearbeite den **Flow-Namen**.
6. Melde dich an und klicke auf **Weiter**.
7. Wähle ein **Team** und einen **Kanal** aus den Listen aus und klicke auf **Flow erstellen**.
8. Kopieren Sie die `MS_TEAMS_HTTP_POST_URL`, speichern Sie sie als Geheimnis in GitHub und klicken Sie auf **Fertig**.

<Admonition type="tip" title="Tip">
  You can use the Test notifications GitHub action to test your connections.
</Admonition>
