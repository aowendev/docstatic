Mit Apple iPadOS können Sie jede beliebige Webseite in eine Web-App umwandeln, die in einer eigenen Safari-Instanz mit einem eigenen Symbol auf Ihrem Startbildschirm ausgeführt wird. Diese Funktion können Sie nutzen, um eine App für das cloudbasierte CMS zu erstellen.

1. Melden Sie sich beim CMS an.
2. Navigieren Sie zu der Sammlung, die Sie als Startseite verwenden möchten. Zum Beispiel die Sammlung **Themen** oder das **Inhaltsverzeichnis**.
3. Tippen Sie auf das Symbol **Teilen**, dann auf **Mehr** ( **…** ) und anschließend auf **Zum Startbildschirm hinzufügen** ( **+** ).
4. Geben Sie der App einen Namen. Standardmäßig wird „TinaCMS“ verwendet.
5. Klicken Sie auf **Hinzufügen**.
