docStatic unterstützt die Suchmaschinenoptimierung auf verschiedene Weise:

* Globale Metadaten
* Für Menschen lesbare Links
* Bild-Metabeschreibung
* Umfangreiche Suchinformationen
* Robots-Datei
* Metadaten auf Einzelseiten
* Sitemap-Datei
* Strukturierte Inhalte

Weitere Informationen finden Sie im Abschnitt [Suchmaschinenoptimierung](https://docusaurus.io/docs/seo) in der Docusaurus-Dokumentation.
