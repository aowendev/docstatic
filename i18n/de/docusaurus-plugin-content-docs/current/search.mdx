# Suche

Standardmäßig ist docStatic für die Verwendung der <Url urlKey="lunr" />-Suche konfiguriert. Der Hauptvorteil dieser Lösung besteht darin, dass sie kostenlos ist. Der größte Nachteil ist, dass der gesamte Suchindex auf den Browser des Benutzers heruntergeladen wird. Je größer Ihre Website ist, desto langsamer wird sie.

Als Docusaurus-Plugins stehen verschiedene Alternativen zur Verfügung, darunter:

* Algolia (vorinstalliert)
* <Url urlKey="markprompt" />
* [Meilisearch](https://github.com/tauri-apps/meilisearch-docsearch)
* [Orama](https://github.com/askorama/orama/tree/main/packages/plugin-docusaurus-v3)
* <Url urlKey="markprompt" linkText={[{ lang: "de", text: "Typesense DocSearch" }]} />

Weitere Informationen finden Sie unter <Url urlKey="docusaurus-search" /> in der Docusaurus-Dokumentation.
