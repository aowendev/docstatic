# Einführung

Die Seitenleiste für Wikis wird automatisch aus der Dateistruktur generiert.

docStatic kann eine Kategorie automatisch mit ihrem Indexdokument verknüpfen.

Ein Kategorie-Indexdokument ist ein Dokument, das dieser Dateinamenskonvention folgt:

Benannt als `README` (Groß-/Kleinschreibung spielt keine Rolle): `docs/wiki/ordner/readme.mdx`.
