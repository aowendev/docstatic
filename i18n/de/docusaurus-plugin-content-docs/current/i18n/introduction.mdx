# Internationalisierung

Der statische Website-Generator bietet Unterstützung für die Internationalisierung (<Url urlKey="wikipedia-i18n" />). Ausführliche Informationen finden Sie unter <Url urlKey="docusaurus-i18n-introduction" /> in der Docusaurus-Dokumentation.

<Admonition type="note" title="Für übersetzte Sidebar-Bezeichnungen ist eine Überschrift 1 erforderlich">
  Die Themenbezeichnung in der Sidebar-Inhaltsübersicht entnimmt das System der gerenderten Überschrift 1 (`# Titel`) eines übersetzten Themas, nicht dem Feld `title` im Frontmatter. Auf einer rein englischsprachigen Website ist die Überschrift 1 optional – der Frontmatter-Titel genügt –, aber sobald Sie eine Website übersetzen, geben Sie jedem Thema eine Überschrift 1, die exakt dem Frontmatter-Titel entspricht. Andernfalls bleibt der Sidebar-Eintrag dieses Themas auf Englisch, selbst nachdem der Rest der Seite übersetzt wurde.
</Admonition>

## Übersetzte Dokumente im CMS bearbeiten

1. Wählen Sie in der Sammlung **Übersetzungen** das Dokument aus, das Sie bearbeiten möchten.
2. Nehmen Sie Ihre Änderungen vor.
3. Setzen Sie den **Dokumentstatus** je nach Bedarf auf **In Übersetzung** oder **Übersetzung genehmigt**.
4. Klicken Sie auf **Speichern**.
