# Internationalisierung

Der statische Website-Generator bietet Unterstützung für die Internationalisierung (<Url urlKey="wikipedia-i18n" />). Ausführliche Informationen finden Sie unter <Url urlKey="docusaurus-i18n-introduction" /> in der Docusaurus-Dokumentation.

## Übersetzte Dokumente im CMS bearbeiten

1. Wählen Sie in der Sammlung **Übersetzungen** das Dokument aus, das Sie bearbeiten möchten.
2. Nehmen Sie Ihre Änderungen vor.
3. Setzen Sie den **Dokumentstatus** je nach Bedarf auf **In Übersetzung** oder **Übersetzung genehmigt**.
4. Klicken Sie auf **Speichern**.
