Der Kern des Static-Site-Generators bietet selbst keine Funktionen. Alle Funktionen werden an einzelne Plugins delegiert: die Dokumentationsfunktion wird vom <Url urlKey="docusaurus-docs-plugin-api-reference" linkText={[{ lang: "de", text: "Docs-Plugin" }]} /> bereitgestellt; die Blog-Funktion, die vom <Url urlKey="docusaurus-blog-plugin-api-reference" linkText={[{ lang: "de", text: "Blog-Plugin" }]} /> bereitgestellt wird; oder einzelne Seiten, die vom <Url urlKey="docusaurus-pages-plugin" /> bereitgestellt werden.

docStatic ist so vorkonfiguriert, dass es die Plugins verwendet, die zur Unterstützung folgender Funktionen erforderlich sind:

* KaTeX-Mathematikformeln
* Lunr-Suche
* Mermaid-Diagramme
* OpenAPI-Dokumentation
* GraphQL-Dokumentation

Weitere Informationen finden Sie unter <Url urlKey="docusaurus-using-plugins" /> in der Docusaurus-Dokumentation.
