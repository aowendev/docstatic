Der Kern des Static-Site-Generators bietet selbst keine Funktionen. Alle Funktionen werden an einzelne Plugins delegiert: die Dokumentationsfunktion wird vom [Docs-Plugin](https://docusaurus.io/docs/api/plugins/@docusaurus/plugin-content-docs) bereitgestellt; die Blog-Funktion, die vom [Blog-Plugin](https://docusaurus.io/docs/api/plugins/@docusaurus/plugin-content-blog) bereitgestellt wird; oder einzelne Seiten, die vom [Pages-Plugin](https://docusaurus.io/docs/api/plugins/@docusaurus/plugin-content-pages) bereitgestellt werden.

docStatic ist so vorkonfiguriert, dass es die Plugins verwendet, die zur Unterstützung folgender Funktionen erforderlich sind:

* KaTeX-Mathematikformeln
* Lunr-Suche
* Mermaid-Diagramme
* OpenAPI-Dokumentation
* GraphQL-Dokumentation

Weitere Informationen finden Sie unter [Verwendung von Plugins](https://docusaurus.io/docs/using-plugins) in der Docusaurus-Dokumentation.
