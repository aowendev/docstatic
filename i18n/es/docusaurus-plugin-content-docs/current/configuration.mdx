# Configuración

La configuración del sitio estático de Docusaurus se gestiona a través del archivo `docusaurus.config.ts`. Para obtener información sobre cómo editar este archivo directamente, consulta [Configuración](https://docusaurus.io/docs/configuration) en la documentación de Docusaurus.

Para utilizar el CMS y editar la configuración, ve a la sección **Configuración**. Desde aquí, puedes configurar lo siguiente del sitio:

* **Título**.
* **Eslogan**.
* **Favicon**.
* **URL del esquema GraphQL**.
* **Modo de color** predeterminado (oscuro o claro).
* Elementos del **pie de página**.
* **Idiomas**.
* **Logotipo**.
* Esquemas **OpenAPI**.
* **Resaltado de sintaxis**.
* **URL**.
* **Barra de navegación**.
* Ajustes de la **barra lateral**.
* Ajustes del **blog**.

Existe una sección independiente llamada **Tema** para cambiar la combinación de colores y los ajustes tipográficos.
