# Optimización para motores de búsqueda (SEO)

docStatic facilita la optimización para motores de búsqueda (SEO) de diversas formas:

* Metadatos globales
* Enlaces legibles para los usuarios
* Metadescripción de las imágenes
* Información de búsqueda enriquecida
* Archivo robots.txt
* Metadatos de una sola página
* Archivo de mapa del sitio
* Contenido estructurado

Para obtener más información, consulta la sección [Optimización para motores de búsqueda](https://docusaurus.io/docs/seo) en la documentación de Docusaurus.
