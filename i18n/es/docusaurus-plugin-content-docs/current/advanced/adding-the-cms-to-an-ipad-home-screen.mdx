# Adding the CMS to an iPad home screen

Con iPadOS de Apple puedes convertir cualquier página web en una aplicación web que se ejecute en su propia instancia de Safari y que tenga su propio icono en la pantalla de inicio. Puedes utilizar esta función para crear una aplicación para el CMS alojado en la nube.

1. Inicia sesión en el CMS.
2. Ve a la colección que quieras utilizar como página de inicio. Por ejemplo, la colección **Temas** o la **Índice**.
3. Pulsa el icono **Compartir**, pulsa **Más** ( **…** ) y pulsa **Añadir a la pantalla de inicio** ( **+** ).
4. Asigna un nombre a la aplicación. Por defecto, se utilizará «TinaCMS».
5. Pulsa **Añadir**.
