# Revisión de estilo

Una de las funciones que más echan en falta los redactores que trabajan con «docs-as-code» es un buen corrector ortográfico, gramatical y de estilo. Por defecto, la revisión ortográfica la proporciona el navegador web o el entorno de desarrollo integrado. Esto puede ser suficiente para sitios web sencillos, pero si necesitas algo más avanzado, necesitarás un corrector gramatical específico.

## LanguageTool

docStatic se ha probado con <Url urlKey="languagetool" />, un corrector gramatical basado en IA que admite más de 20 idiomas. El <Url urlKey="langaugetool-register" linkText={[{ lang: "es", text: "registro" }]} /> para el plan básico es gratuito. El <Url urlKey="langaugetool-premium" /> añade compatibilidad con guías de estilo para particulares y equipos. Hay disponibles planes personalizados para [empresas](https://languagetool.org/sales). También hay un <Url urlKey="langaugetool-premium" linkText={[{ lang: "es", text: "descuento" }]} /> para estudiantes y organizaciones sin ánimo de lucro.

## Autohospedado

Dado que LanguageTool es de código abierto, tienes la opción de <Url urlKey="langaugetool-development" linkText={[{ lang: "es", text: "autohospedarlo" }]} />. En este caso no hay cuotas de suscripción, pero necesitarás un equipo de desarrollo para configurar tu instancia de LanguageTool y tendrás que encargarte tú mismo del soporte técnico.
