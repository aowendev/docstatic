# Blog

La función de blog te permite crear artículos con fecha y hora.

<Admonition type="info" title="Información">
  Refer to <Url urlKey="docusaurus-blog-plugin-api-reference" /> in the Docusaurus documentation for an exhaustive list of options.
</Admonition>

1. En la colección **Artículos del blog** del CMS, haz clic en **Añadir archivo**.
2. Asigna un **Título**.
3. Añade los **autores**. Para cada autor, edita el componente y añade:
   1. Su **nombre**.
   2. Su **cargo**.
   3. Una **URL**.
   4. Una **URL de imagen**.
4. Selecciona la **Fecha** de publicación. En el entorno de producción, los artículos con fecha futura no aparecerán hasta que se vuelva a generar el sitio. Sin embargo, sí aparecerán al ejecutar el servidor de desarrollo (`npm run dev`).
5. (Opcional) Añade las **Etiquetas** de taxonomía que desees.
6. Introduce el contenido.
7. Haz clic en **Guardar**.

Para obtener más información, consulta <Url urlKey="docusaurus-blog" /> en la documentación de Docusaurus.
