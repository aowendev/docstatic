# Internacionalización

El generador de sitios web estáticos ofrece compatibilidad con la internacionalización ([i18n](https://en.wikipedia.org/wiki/Internationalization_and_localization)). Para obtener información detallada, consulta [i18n - Introducción](https://docusaurus.io/docs/i18n/introduction) en la documentación de Docusaurus.

## Editar documentos traducidos en el CMS

1. En la colección **Traducciones**, selecciona el documento que deseas editar.
2. Realice los cambios.
3. Establezca el **Estado del documento** en **En traducción** o **Traducción aprobada**, según sea necesario.
4. Haga clic en **Guardar**.
