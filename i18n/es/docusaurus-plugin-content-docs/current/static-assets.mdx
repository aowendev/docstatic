Los recursos estáticos son los archivos que no son código y que se copian directamente en el resultado de la compilación. Entre ellos se incluyen imágenes, hojas de estilo, favicons, fuentes, etc.

Debes colocar estos recursos en la carpeta `static`. Todos los archivos que coloques en esa carpeta se copiarán en la raíz de la carpeta de compilación generada, conservando la jerarquía de carpetas. Por ejemplo, si añades un archivo llamado `sun.jpg` a la carpeta `static`, se copiará en `build/sun.jpg`.

Esto significa que:

* Para un sitio con `baseUrl: '/'`, la imagen `/static/img/sun.jpg` se servirá en `/img/sun.jpg`.
* Para un sitio con `baseUrl: '/subpath/'`, la imagen `/static/img/sun.jpg` se mostrará en `/subpath/img/sun.jpg`.

## Cómo hacer referencia a tus recursos estáticos

### En el CMS

1. Inserta un enlace.
2. Introduce la ruta absoluta, por ejemplo, /files/note.docx.
3. Introduce el texto que se va a mostrar.

### En Markdown

```markdown
You write a link like this: [Download this document](/files/note.docx)

Docusaurus changes that to: <a href={require('static/files/note.docx')}>Download this document</a>
```

Para obtener más información, consulta [Recursos estáticos](https://docusaurus.io/docs/static-assets) en la documentación de Docusaurus.
