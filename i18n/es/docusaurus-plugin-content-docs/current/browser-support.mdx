docStatic te permite definir la lista de navegadores compatibles mediante una [configuración de la lista de navegadores](https://github.com/browserslist/browserslist). Por lo general, los sitios web deberían funcionar correctamente en cualquier navegador moderno.

Para obtener más información, consulta la sección [Compatibilidad con navegadores](https://docusaurus.io/docs/browser-support) en la documentación de Docusaurus.

## Edición en el CMS

TinaCMS es totalmente compatible con:

* Chrome
* Edge
* Safari

<Admonition type="danger" title="Warning">
  TinaCMS has known issues with Firefox that can range from character styles being ignored to work not being saved. You should use a different browser.
</Admonition>
