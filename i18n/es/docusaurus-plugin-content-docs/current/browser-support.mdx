# Browser support

docStatic te permite definir la lista de navegadores compatibles mediante una [configuración de la lista de navegadores](https://github.com/browserslist/browserslist). Por lo general, los sitios web deberían funcionar correctamente en cualquier navegador moderno.

Para obtener más información, consulta la sección <Url urlKey="docusaurus-browser-support" /> en la documentación de Docusaurus.

## Edición en el CMS

TinaCMS es totalmente compatible con:

* Chrome
* Edge
* Safari

<Admonition type="danger" title="Advertencia">
  TinaCMS presenta problemas conocidos con Firefox que pueden ir desde que se ignoren los estilos de carácter hasta que no se guarden los cambios. Te recomendamos que utilices otro navegador.
</Admonition>
