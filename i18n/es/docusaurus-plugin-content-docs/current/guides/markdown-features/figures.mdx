# Figuras

El componente Figura te permite añadir imágenes con leyendas a un tema. Cuando un usuario hace clic en una figura, esta se muestra a la máxima ampliación dentro de un lightbox.

1. Seleccione **Figura** en la lista **Incrustar**.
2. Edite el componente.
3. Seleccione una imagen del Gestor de medios.
4. Introduzca una **Leyenda**. También se utilizará como texto alternativo para lectores de pantalla.
5. (Opcional) Introduzca un tamaño.
