# Comentarios

El componente **Comentario** te permite añadir comentarios que son visibles en el CMS, pero no en la página final, ni siquiera en el código fuente sin procesar.

1. Selecciona **Comentario** en la lista **Incrustar**.
2. Edita el componente.
3. Introduce un **Revisor**.
4. Introduce un **Comentario**.
