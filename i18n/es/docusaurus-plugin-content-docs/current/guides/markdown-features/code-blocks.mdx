# Bloques de código y fragmentos de código

docStatic ofrece dos formas de incluir código en tu documentación. Ambas admiten el resaltado de sintaxis.

## Bloques de código

1. Haz clic en el icono **Bloque de código** del editor de texto enriquecido.
2. Haz clic en la lista de lenguajes y selecciona o busca un lenguaje.
3. Introduce tu código en el cuadro.

#### Ejemplo:

```plaintext
This is some plain text.
```

## Fragmentos de código

1. Selecciona **Fragmento de código** en la lista **Incrustar**.
2. Asigna un **Título**.
3. Selecciona un **Lenguaje**.
4. Elige un archivo de la lista. La lista se rellena con todos los archivos de la carpeta `reuse/code/` cada vez que ejecutas el servidor de desarrollo o realizas una compilación.

#### Ejemplo:

<CodeSnippet title="Example Title" language="xml" filepath="example.xml" />

La ventaja de utilizar fragmentos de código es que existe un archivo físico que se puede someter a pruebas unitarias.
