# Notas al pie

Existe una extensión de Markdown que ofrece notas al pie, pero su implementación no es uniforme y separa el contenido del número. Por ejemplo:

```markdown
Markdown es un lenguaje de marcado ligero[^1] creado por John Gruber[^2], hoy ampliamente utilizado en la escritura[^3].

[^1]: Markdown usa una sintaxis sencilla para dar formato al texto.
[^2]: John Gruber creó Markdown en 2004.
[^3]: Muchas plataformas, como GitHub, Stack Overflow y los blogs, admiten Markdown.
```

En docStatic, esto se representaría así:

```markdown
Markdown es un lenguaje de marcado ligero<Footnote summary="1"> Markdown usa una sintaxis sencilla para dar formato al texto.</Footnote>
creado por John Gruber<Footnote summary="2">John Gruber creó Markdown en 2004.</Footnote>,
hoy ampliamente utilizado en la escritura<Footnote summary="3">Muchas plataformas, como GitHub, Stack Overflow y los blogs, admiten Markdown.</Footnote>.
```

El componente **Notas al pie** le permite añadir notas al pie en línea a su texto.

1. Seleccione **Notas al pie** en la lista **Incrustar**.
2. Edite el componente.
3. Asígnele un **Resumen**.
4. Introduzca la **Nota al pie**.

#### Ejemplo

Markdown es un lenguaje de marcado ligero<Footnote summary="1"> Markdown usa una sintaxis sencilla para dar formato al texto.</Footnote> creado por John Gruber<Footnote summary="2">John Gruber creó Markdown en 2004.</Footnote>, hoy ampliamente utilizado en la escritura<Footnote summary="3">Muchas plataformas, como GitHub, Stack Overflow y los blogs, admiten Markdown.</Footnote>.

Las notas al pie se numeran en el orden en que aparecen, y las notas propiamente dichas se recopilan al final de la página. La numeración se calcula al compilar el sitio, de modo que los números y las notas ya están en la página tal como se sirve, en lugar de ser ensamblados por el navegador.

## Repetir una nota al pie

Dos notas al pie con el mismo contenido son la misma nota. Comparten un número y aparecen una sola vez al final de la página, de modo que un punto que necesite repetir no satura la lista.

<Admonition type="info" title="Ejemplo">
  Markdown cuenta con amplio soporte<Footnote summary="Soporte de plataformas">Muchas plataformas, entre ellas GitHub y Stack Overflow, admiten Markdown.</Footnote>, al igual que su sintaxis de tablas<Footnote summary="Soporte de plataformas">Muchas plataformas, entre ellas GitHub y Stack Overflow, admiten Markdown.</Footnote>.
</Admonition>

Ambas marcas anteriores apuntan a la misma nota, porque su texto es idéntico. Cambie una de ellas y pasará a ser una nota propia.

## Notas al pie y citas

Con un estilo de cita de **nota**, una cita es también una nota al pie, y las citas comparten esta misma secuencia numerada. Consulte [Citas](./citations.mdx) para saber cómo funciona y qué aspecto tiene.
