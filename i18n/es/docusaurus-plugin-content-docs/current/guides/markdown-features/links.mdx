# Enlaces en Markdown

Hay dos formas de añadir un enlace a otra página: mediante una ruta URL o una ruta de archivo.

```
- [URL path to another document](./installation)
- [file path to another document](./installation.mdx)
```

En el CMS puedes añadir un enlace desde el portapapeles seleccionando un fragmento de texto y pegándolo.

También puedes resaltar una sección de texto y hacer clic en el icono «Enlace» para añadir una ruta.

O bien, puedes colocar el cursor donde quieras que aparezca el enlace, hacer clic en el icono e introducir la ruta y el texto que se mostrará.

Para obtener más información sobre los enlaces, consulta [Enlaces Markdown](https://docusaurus.io/docs/markdown-features/links) en la documentación de Docusaurus.
