# Ecuaciones matemáticas

Las ecuaciones matemáticas se pueden representar utilizando <Url urlKey="katex" />.

## Uso

Para utilizar KaTeX desde el CMS, incrusta la cadena en un componente **Passthrough**. Puedes incluir un **Resumen** que aparecerá en línea al editar el tema.

### En línea

Escribe ecuaciones matemáticas en línea envolviendo las ecuaciones LaTeX entre \`

        path\:guides/markdown-features/math-equations.mdx
        title\:Math equations

        \# Math equations

Mathematical equations can be rendered using <Url urlKey="katex" />.

## Use

To use KaTeX from the CMS, embed the string in a **Passthrough** component. You can include a **Summary** that will appear inline when editing the topic.

### Inline

Write inline math equations by wrapping LaTeX equations between `$`:

```latex
Let $f\colon[a,b]\to\R$ be Riemann integrable. Let $F\colon[a,b]\to\R$ be
$F(x)=\int_{a}^{x} f(t)\,dt$. Then $F$ is continuous, and at all $x$ such that
$f$ is continuous at $x$, $F$ is differentiable at $x$ with $F'(x)=f(x)$.
```

<Passthrough type="markdown" string="Let $f\colon[a,b] \to \R$ be Riemann integrable. Let $F\colon[a,b]\to\R$ be $F(x)=\int_{a}^{x} f(t)\,dt$. Then $F$ is continuous, and at all $x$ such that $f$ is continuous at $x$, $F$ is differentiable at $x$ with $F'(x)=f(x)$." summary="inline equation" />

### Blocks

For equation block or display mode, use line breaks and `$$`:

```latex
$$
I = \int_0^{2\pi} \sin(x)\,dx
$$
```

<Passthrough type="markdown" string="\n$$\nI = \int_0^{2\pi} \sin(x)\,dx\n$$\n" summary="block equation" />

For more information, refer to the <Url urlKey="katex" /> documentation.
