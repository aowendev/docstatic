# Texto condicional

El componente **Texto condicional** te permite incluir contenido dentro de un conjunto de condiciones que determinan cuándo debe mostrarse:

* Las condiciones pueden ser cualquier combinación de idiomas o condiciones definidas por el usuario.
* El contenido puede mostrarse u ocultarse si se cumple una o más condiciones (O) o solo si se cumplen todas las condiciones (Y).
  También puedes especificar un texto alternativo que se mostrará si no se cumple ninguna condición.

## Crear categorías y condiciones

1. En el CMS, haz clic en la colección **Condiciones**.
2. Haz clic en el icono **Añadir** para añadir una nueva **Categoría**
3. Asigna un **Nombre** y una **Descripción**.
4. Para cada **Condición** que desee añadir:
   1. Haga clic en el icono **Añadir**.
   2. Asigne un nombre a la **Condición** y añádale una **Descripción**.
   3. Active o desactive el estado **Activo** de la condición según sea necesario.

## Añadir condiciones a un tema

Las condiciones se establecen a nivel de tema. El idioma viene determinado por el idioma de la página. El resto de condiciones se definen como una matriz en los metadatos al inicio del tema.

1. Crea o edita un tema.
2. En el área **Condiciones**, despliega **Categorías** y marca la casilla de cualquier **Condición** que desees aplicar al tema.

## Añadir texto condicional

1. Selecciona **Texto condicional** en la lista **Incrustar**.
2. Edita el componente.
3. Introduce el **Contenido**.
4. Establece la **Acción** (mostrar u ocultar).
5. Añade las **Condiciones requeridas**.
6. Añade los **Idiomas requeridos**.
7. Establece la **Lógica de condiciones**.
8. Configura la **Lógica de idioma**.
9. Selecciona si se requieren tanto las condiciones como los idiomas.
10. (Opcional) Introduce el **Texto alternativo**.

### Ejemplo

<ConditionalText action="show" conditions={["production"]} languages={[]} logic="any" languageLogic="any" requireBothConditions={false} fallback="">
  The `production` condition is set on this page.
</ConditionalText>
