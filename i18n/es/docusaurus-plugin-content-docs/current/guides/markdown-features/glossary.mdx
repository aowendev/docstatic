# Términos del glosario

El componente **Término del glosario** te permite introducir una clave que se asocia a un término localizado y a una descripción. El término aparece subrayado. Al pasar el cursor por encima del término, aparece el cursor de ayuda, y al mantenerlo sobre él se muestra la descripción en forma de información sobre herramientas. En dispositivos con pantalla táctil, al pulsar sobre el término se muestra una ventana emergente con la definición.

## Gestión de términos del glosario

Puedes editar la colección «Términos del glosario» en el CMS.

1. Haz clic en el icono **Añadir** ( **+** ) para añadir una nueva **Clave**.
2. Edita la clave y, a continuación, haz clic en el icono **Añadir** ( **+** ) para añadir una nueva **Traducción**.
3. Edita la traducción.
4. Asigna un **código de idioma**.
5. Introduce cómo debe aparecer el **término** en el texto.
6. **Introduce la definición.**

El término del glosario utilizará la versión lingüística de la página en la que se muestre. Si no existe ninguna definición, se utilizará el idioma de origen.

## Uso de términos del glosario

1. Selecciona **Término del glosario** en la lista **Incrustar**.
2. Edita el componente.
3. Introduce la **clave**.
