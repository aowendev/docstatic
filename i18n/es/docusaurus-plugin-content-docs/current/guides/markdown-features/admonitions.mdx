# Advertencias

El componente **Advertencias** te permite añadir advertencias con estilo.

1. Selecciona **Advertencia** en la lista **Incrustar**.
2. Edita el componente y selecciona un **Tipo** (**Nota**, **Consejo**, **Información**, **Precaución** o **Advertencia**).
3. Asigna un **Título**.
4. Introduce el **Contenido**.

#### Ejemplos:

<Admonition type="note" title="Nota">
  Utiliza las notas de advertencia para aportar información complementaria.
</Admonition>

<Admonition type="tip" title="Consejo">
  Utiliza las advertencias de los consejos para indicar que se pueden ignorar sin problema.
</Admonition>

<Admonition type="info" title="Información">
  Utiliza las advertencias informativas para aquella información que sea lo suficientemente importante como para que destaque del resto del texto.
</Admonition>

<Admonition type="caution" title="Precaución">
  Utiliza advertencias de precaución cuando haya algo que pueda impedir que se lleve a cabo una acción prevista.
</Admonition>

<Admonition type="danger" title="Advertencia">
  Utiliza advertencias cuando exista riesgo de lesiones, de vulneración de la seguridad o de pérdida de datos.
</Admonition>
