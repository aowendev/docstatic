El componente **CalsTable** añade compatibilidad con el [modelo de tabla CALS](https://www.oasis-open.org/specs/tm9901.html) utilizado por DocBook y DITA: celdas fusionadas, anchos y alineación por columna, y control detallado de los bordes. Un editor gráfico de cuadrículas integrado en el CMS se encarga de la estructura —fusionar y dividir celdas, insertar y eliminar filas y columnas— para que nunca tengas que editar manualmente los datos subyacentes de la tabla.

1. Selecciona **Tabla CALS** en la lista **Incrustar**.
2. Utiliza los controles **Marco**, **Título** y **A lo ancho de la página** situados en la parte superior para configurar el borde exterior, el título y el ancho de la tabla.
3. Haz clic en una celda para seleccionarla. Mantén pulsada la tecla Mayús y haz clic, o arrastra el cursor, para seleccionar un rango rectangular de celdas.
4. Haz clic en **Combinar** para unir las celdas seleccionadas, o en **Dividir** para deshacer una combinación. La opción **Combinar** solo está habilitada cuando la selección es un rectángulo limpio que no atraviesa una celda combinada existente.
5. Utiliza **Insertar fila arriba/abajo**, **Eliminar fila**, **Insertar columna a la izquierda/derecha** y **Eliminar columna** para cambiar la forma de la cuadrícula.
6. Haz doble clic en una celda para editar su contenido. El contenido de las celdas está en Markdown, por lo que funcionan `**negrita**`, `*cursiva*`, los enlaces y el código en línea.
7. **Guarda** los cambios.

<Admonition type="note" title="Scope">
    Each table supports one header, body and footer section with a single set of columns. DocBook's multiple-`tgroup`-per-table and nested-table (`entrytbl`) features aren't supported.
</Admonition>

#### Ejemplo:

(jsx\:CalsTable table={{ frame: "all", title: "Release channels", tgroup: { cols: 3, colspecs: \[ { colname: "c1", colwidth: "1*" }, { colname: "c2", colwidth: "1*" }, { colname: "c3", colwidth: "1\*" } ], thead: { rows: \[ { entries: \[ { content: "Channel" }, { content: "Cadence" }, { content: "Support" } ] } ] }, tbody: { rows: \[ { entries: \[ { content: "Stable" }, { content: "Monthly" }, { content: "Full", morerows: 1 } ] }, { entries: \[{ content: "Beta" }, { content: "Weekly" }] }, { entries: \[ { content: "Nightly", namest: "c1", nameend: "c2" }, { content: "None" } ] } ] } }, pgwide: true }}/)

Para obtener más información sobre el modelo subyacente, consulta la [referencia del modelo de tabla CALS](https://www.oasis-open.org/specs/tm9901.html) o la [documentación sobre tablas de DocBook](https://tdg.docbook.org/tdg/5.2/table.html).
