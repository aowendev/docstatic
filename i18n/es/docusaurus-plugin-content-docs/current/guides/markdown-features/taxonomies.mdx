# Etiquetas de taxonomía

Las etiquetas de taxonomía te permiten aplicar una [arquitectura de la información](https://en.wikipedia.org/wiki/Information_architecture) al contenido de tu sitio web. Deben aplicarse a cualquier plataforma de documentación que utilices, como los sistemas de seguimiento de errores y los wikis. Los requisitos más restrictivos que probablemente te encontrarás son los sistemas planos (no jerárquicos) que solo admiten letras minúsculas y guiones bajos (`_`) sin espacios.

docStatic aplica una jerarquía de tres niveles a las etiquetas de taxonomía. Para evitar que las etiquetas alcancen una longitud excesiva, el anidamiento se limita a una profundidad máxima de tres niveles. En algunos casos, esto requiere aplanar la estructura (por ejemplo, aunque `regions_europe_uk_scotland` sea lógico, tiene cuatro niveles, por lo que debe estructurarse como `regions_uk_scotland`).

Al diseñar una arquitectura de información de tres niveles, se recomienda intentar tener unas diez categorías de nivel superior, siete de nivel intermedio y tantas categorías de nivel hoja como sean necesarias. Debes escribir las siglas y abreviaturas completas, y tratar de evitar la redundancia.

## Edición de etiquetas de taxonomía

1. En la colección **Taxonomías**, **Añade** una taxonomía.
2. Asígnale una **Etiqueta** utilizando únicamente letras minúsculas.
3. Añade cualquier **Hijo** y asígnales una etiqueta que comience por la etiqueta principal seguida de un guión bajo.
4. Para cada hijo, añade cualquier hijo.

<Admonition type="note" title="Note">
  You can enter tags without the preceding tag name and an underscore, but if you do when adding them to a topic, they will be presented as a flat list.
</Admonition>
