# Metadatos de encabezado

docStatic configura automáticamente metadatos útiles para la página en `<html>`, `<head>` y `<body>`.
Es posible añadir metadatos adicionales (o sobrescribir los existentes) con la etiqueta `<head>` en los archivos Markdown.

En el CMS, esto debe añadirse en el editor de Markdown. No se reconocerá si lo incluyes dentro del componente **Passthrough**.

Para obtener más información, consulta [Metadatos de cabecera](https://docusaurus.io/docs/markdown-features/head-metadata) en la documentación de Docusaurus.
