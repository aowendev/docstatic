# Diagramas

Los diagramas se pueden generar utilizando <Url urlKey="mermaid" /> en un bloque de código.

## Uso

El CMS permite editar directamente diagramas de Mermaid.

1. Haz clic en el icono **Mermaid**.
2. Introduce el código Markdown en el cuadro.

Haz clic en **Vista previa** para ver tu diagrama.

#### Ejemplo:

```mermaid
graph TD;
    A-->B;
    A-->C;
    B-->D;
    C-->D;
```

<Admonition type="note" title="Nota">
  Actualmente, los diagramas zenUML no son compatibles y los diagramas de mapas mentales pueden presentar un comportamiento anómalo. No todos los tipos de diagramas se pueden previsualizar en el CMS.
</Admonition>

Para obtener más información, consulta [Mermaid](https://tina.io/docs/reference/rich-text-usage/mermaid) en la documentación de TinaCMS.

Para obtener información sobre cómo personalizar el aspecto de Mermaid, consulta <Url urlKey="docusaurus-diagrams" /> en la documentación de Docusaurus.

## Ejemplos

### Diagrama de arquitectura

```mermaid
architecture-beta
    group site(cloud)[Site]
    service cms(server)[CMS] in site
    service store(database)[Content] in site
    service pdf(server)[Exporter] in site
    cms:R --> L:store
    store:R --> L:pdf
```

### Diagrama de bloques

```mermaid
block-beta
    columns 3
    Parser["Parser"] Resolver["Resolver"] Composer["Composer"]
    space:3
    PDF["PDF"]:3
```

### Diagrama de contexto C4

```mermaid
C4Context
    title Publishing system
    Person(author, "Author", "Writes topics")
    System(cms, "CMS", "Edits content")
    System(exporter, "PDF exporter", "Produces books")
    Rel(author, cms, "Edits")
    Rel(cms, exporter, "Feeds")
```

### Diagrama de clases

```mermaid
classDiagram
    class Chapter {
        +string Title
        +int Depth
        +VisibleBlocks()
    }
    class Book {
        +Compose()
    }
    Book "1" *-- "many" Chapter : contains
```

### Diagrama entidad-relación

```mermaid
erDiagram
    TOPIC ||--o{ TAG : carries
    TOPIC ||--o{ SNIPPET : includes
    TOPIC {
        string title
        bool published
    }
```

### Diagrama de flujo

```mermaid
flowchart TD
    Start([Start]) --> Input[/Read topic/]
    Input --> Check{Valid?}
    Check -->|Yes| Render[Render PDF]
    Check -->|No| Warn[Warn and continue]
    Render --> Done([Done])
    Warn --> Done
```

### Diagrama de Gantt

```mermaid
gantt
    title Release schedule
    dateFormat YYYY-MM-DD
    section Content
    Draft topics      :a1, 2026-01-06, 10d
    Review            :after a1, 5d
    section Build
    Export PDFs       :2026-01-26, 3d
```

### Diagrama de requisitos

```mermaid
requirementDiagram
    requirement print_fidelity {
        id: 1
        text: Diagrams must render as vectors.
        risk: medium
        verifymethod: test
    }
    element exporter {
        type: application
    }
    exporter - satisfies -> print_fidelity
```
