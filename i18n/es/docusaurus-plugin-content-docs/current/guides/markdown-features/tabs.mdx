El componente **Pestañas** te permite añadir contenido con pestañas a tu tema.

1. Selecciona **Pestañas** en la lista **Incrustar**.
2. Edita el componente.
3. Para cada pestaña:
   1. Selecciona **Elemento de pestaña** en la lista **Incrustar**.
   2. Asigna un **Valor**.
   3. Asigna un **Título**.
   4. Introduce el **Contenido**.
   5. (Opcional) Establece esta pestaña como **Predeterminada**.
4. **Guarda** los cambios.

<Admonition type="danger" title="Warning">
  The CMS can lose context when editing tabs. You should save often. The CMS can get into a position where it cannot find the context of the tab. In this case click the **Raw Markdown** icon and make changes directly in the Markdown. Save and then return to the rich text editor.
</Admonition>

#### Ejemplo:

<Tabs>
  <TabItem label="Apple" value="apple">
    This is an apple 🍎
  </TabItem>

  <TabItem label="Orange" value="orange">
    This is an orange 🍊
  </TabItem>

  <TabItem label="Banana" value="banana">
    This is a banana 🍌
  </TabItem>
</Tabs>

Para obtener más información, consulta [Pestañas](https://docusaurus.io/docs/markdown-features/tabs) en la documentación de Docusaurus.
