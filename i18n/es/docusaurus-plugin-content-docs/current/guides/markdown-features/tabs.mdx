# Tabs

El componente **Pestañas** te permite añadir contenido con pestañas a tu tema.

1. Selecciona **Pestañas** en la lista **Incrustar**.
2. Edita el componente.
3. Para cada pestaña:
   1. Selecciona **Elemento de pestaña** en la lista **Incrustar**.
   2. Asigna un **Valor**.
   3. Asigna un **Título**.
   4. Introduce el **Contenido**.
   5. (Opcional) Establece esta pestaña como **Predeterminada**.
4. **Guarda** los cambios.

<Admonition type="danger" title="Advertencia">
  El CMS puede perder el contexto al editar pestañas. Es recomendable guardar con frecuencia. El CMS puede llegar a una situación en la que no consiga encontrar el contexto de la pestaña. En ese caso, haz clic en el icono **Raw Markdown** y realiza los cambios directamente en el código Markdown. Guarda los cambios y, a continuación, vuelve al editor de texto enriquecido.
</Admonition>

#### Ejemplo:

<Tabs>
  <TabItem label="Apple" value="apple">
    This is an apple 🍎
  </TabItem>

  <TabItem label="Orange" value="orange">
    This is an orange 🍊
  </TabItem>

  <TabItem label="Banana" value="banana">
    This is a banana 🍌
  </TabItem>
</Tabs>

Para obtener más información, consulta <Url urlKey="docusaurus-tabs" /> en la documentación de Docusaurus.
