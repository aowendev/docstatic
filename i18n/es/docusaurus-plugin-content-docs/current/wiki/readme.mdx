# Introducción

La barra lateral de los wikis se genera automáticamente a partir de la estructura de archivos.

docStatic puede vincular automáticamente una categoría a su documento índice.

Un documento índice de categoría es un documento que sigue esta convención de nombres de archivo:

Denominado `README` (sin distinción entre mayúsculas y minúsculas): `docs/wiki/carpeta/readme.mdx`.
