El núcleo del generador de sitios estáticos no ofrece ninguna funcionalidad propia. Todas las funcionalidades se delegan a plugins individuales: la funcionalidad de documentación la proporciona el [plugin de documentación](https://docusaurus.io/docs/api/plugins/@docusaurus/plugin-content-docs); la función de blog, proporcionada por el [complemento de blog](https://docusaurus.io/docs/api/plugins/@docusaurus/plugin-content-blog); o las páginas individuales proporcionadas por el [complemento de páginas](https://docusaurus.io/docs/api/plugins/@docusaurus/plugin-content-pages).

docStatic viene preconfigurado para utilizar los complementos necesarios para admitir:

* Ecuaciones matemáticas KaTeX
* Búsqueda con Lunr
* Diagramas con Mermaid
* Documentación de OpenAPI
* Documentación de GraphQL

Para obtener más información, consulta [Uso de complementos](https://docusaurus.io/docs/using-plugins) en la documentación de Docusaurus.
