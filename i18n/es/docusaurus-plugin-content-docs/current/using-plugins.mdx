El núcleo del generador de sitios estáticos no ofrece ninguna funcionalidad propia. Todas las funcionalidades se delegan a plugins individuales: la funcionalidad de documentación la proporciona el <Url urlKey="docusaurus-docs-plugin-api-reference" linkText={[{ lang: "es", text: "plugin de documentación" }]} />; la función de blog, proporcionada por el <Url urlKey="docusaurus-blog-plugin-api-reference" linkText={[{ lang: "es", text: "complemento de blog" }]} />; o las páginas individuales proporcionadas por el <Url urlKey="docusaurus-pages-plugin" />.

docStatic viene preconfigurado para utilizar los complementos necesarios para admitir:

* Ecuaciones matemáticas KaTeX
* Búsqueda con Lunr
* Diagramas con Mermaid
* Documentación de OpenAPI
* Documentación de GraphQL

Para obtener más información, consulta <Url urlKey="docusaurus-using-plugins" /> en la documentación de Docusaurus.
