The static site generator core doesn't provide any feature of its own. All features are delegated to individual plugins: the docs feature provided by the <Url urlKey="docusaurus-docs-plugin-api-reference" linkText={[{ lang: "en", text: "docs plugin" }]} />; the blog feature provided by the <Url urlKey="docusaurus-blog-plugin-api-reference" linkText={[{ lang: "en", text: "blog plugin" }]} />; or individual pages provided by the <Url urlKey="docusaurus-pages-plugin" linkText={[{ lang: "en", text: "pages plugin" }]} />.

docStatic is preconfigured to use the plugins required to support:

* KaTeX math equations
* Lunr search
* Mermaid diagrams
* OpenAPI docs
* GraphQL docs

For more information, refer to <Url urlKey="docusaurus-using-plugins" /> in the Docusaurus documentation.
