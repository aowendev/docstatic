# Footnotes

There is an extension to Markdown that provides footnotes, but its implementation is not consistent and it separates the content from the number. For example:

```markdown
Markdown is a lightweight markup language[^1] created by John Gruber[^2], now widely used in writing[^3].

[^1]: Markdown uses simple syntax to achieve text formatting.
[^2]: John Gruber created Markdown in 2004.
[^3]: Many platforms such as GitHub, Stack Overflow, and blog platforms support Markdown.
```

In docStatic this would be represented as:

```markdown
Markdown is a lightweight markup language<Footnote summary="1"> Markdown uses simple syntax to achieve text formatting.</Footnote>
created by John Gruber<Footnote summary="2">John Gruber created Markdown in 2004.</Footnote>,
now widely used in writing<Footnote summary="3">Many platforms such as GitHub, Stack Overflow, and blog platforms support Markdown.</Footnote>.
```

The **Footnotes** component enables you add inline footnotes to your text.

1. Select **Footnotes** from the **Embed** list.
2. Edit the component.
3. Give it a **Summary**.
4. Enter the **Footnote**.

#### Example

Markdown is a lightweight markup language<Footnote summary="1"> Markdown uses simple syntax to achieve text formatting.</Footnote> created by John Gruber<Footnote summary="2">John Gruber created Markdown in 2004.</Footnote>, now widely used in writing<Footnote summary="3">Many platforms such as GitHub, Stack Overflow, and blog platforms support Markdown.</Footnote>.

Footnotes are numbered in the order they appear, and the notes themselves are collected at the foot of the page. The numbering is worked out when the site is built, so the numbers and the notes are in the page as served rather than being assembled by the browser.

## Repeating a footnote

Two footnotes with the same content are the same note. They share a number and appear once at the foot of the page, so a point you need to make twice does not clutter the list.

<Admonition type="info" title="Example">
  Markdown is widely supported<Footnote summary="Platform support">Many platforms, including GitHub and Stack Overflow, support Markdown.</Footnote>, and so is its table syntax<Footnote summary="Platform support">Many platforms, including GitHub and Stack Overflow, support Markdown.</Footnote>.
</Admonition>

Both markers above point at the same note, because the text inside them is identical. Change one of them and it becomes a note of its own.

## Footnotes and citations together

When the site uses a **note** citation style—Oxford, or Chicago (notes and bibliography)—a citation is also a footnote. Citations and your own footnotes then share **one** numbered sequence, in the order they appear on the page.

A citation can also go inside a footnote, which puts the source and your own remark in a single note rather than two:

<Admonition type="info" title="Example">
  Reuse is not free<Footnote summary="On the cost of reuse"><Cite items={[{ key: "jones2019" }]} /> This argues the costs outweigh the savings.</Footnote>, whatever the tooling promises<Cite items={[{ key: "smith2020", locator: "14", label: "page" }]} />.
</Admonition>

Under an in-text style the citation in that second sentence appears in the sentence itself, and only the footnote is numbered. Under a note style both are notes, numbered in sequence with every other note on this page.

See [Citations](./citations.mdx) for how to choose the style and manage sources.
