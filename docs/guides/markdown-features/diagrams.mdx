# Diagrams

Diagrams can be rendered using <Url urlKey="mermaid" /> in a code block.

## Use

The CMS directly supports editing Mermaid diagrams.

1. Click the **Mermaid** icon.
2. Enter the Markdown in the box.

Click **Preview** to view your diagram.

<Admonition type="note" title="Note">
  Currently, zenUML diagrams are not supported and mind map diagrams may produce unusual behaviour. Not all diagram types can be previewed in the CMS.
</Admonition>

For more information, refer to [Mermaid](https://tina.io/docs/reference/rich-text-usage/mermaid) in the TinaCMS documentation.

For information on theming Mermaid, refer to <Url urlKey="docusaurus-diagrams" /> in the Docusaurus documentation.

## Examples

### Architecture diagram

```mermaid
architecture-beta
    group site(cloud)[Site]
    service cms(server)[CMS] in site
    service store(database)[Content] in site
    service pdf(server)[Exporter] in site
    cms:R --> L:store
    store:R --> L:pdf
```

### Block diagram

```mermaid
block-beta
    columns 3
    Parser["Parser"] Resolver["Resolver"] Composer["Composer"]
    space:3
    PDF["PDF"]:3
```

### C4 context diagram

```mermaid
C4Context
    title Publishing system
    Person(author, "Author", "Writes topics")
    System(cms, "CMS", "Edits content")
    System(exporter, "PDF exporter", "Produces books")
    Rel(author, cms, "Edits")
    Rel(cms, exporter, "Feeds")
```

### Class diagram

```mermaid
classDiagram
    class Chapter {
        +string Title
        +int Depth
        +VisibleBlocks()
    }
    class Book {
        +Compose()
    }
    Book "1" *-- "many" Chapter : contains
```

### Entity relationship diagram

```mermaid
erDiagram
    TOPIC ||--o{ TAG : carries
    TOPIC ||--o{ SNIPPET : includes
    TOPIC {
        string title
        bool published
    }
```

### Flowchart

```mermaid
flowchart TD
    Start([Start]) --> Input[/Read topic/]
    Input --> Check{Valid?}
    Check -->|Yes| Render[Render PDF]
    Check -->|No| Warn[Warn and continue]
    Render --> Done([Done])
    Warn --> Done
```

```mermaid

        id: 1

        type: application
```
